# 商品購買行動

| 購買の種類             | 内容                                                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 計画購買               | 来店時から購買する意思を持って、購買に至る購買行動                                                                   |
| （非計画購買）         | 来店時には購買する意図がなかったが、店舗などの商品をみて、購買の意思決定をする購買行動                               |
| （非計画購買）想起購買 | 家庭内の在庫切れなど、店頭で商品やPOPを見て商品の必要性を思い出し購入する購買活動                                    |
| （非計画購買）関連購買 | 他の購入商品との関連性から店舗内で必要性を認識し、商品を購入する購買行動                                             |
| （非計画購買）条件購買 | 来店時には明確な購買意図を持っていないが、値引きなどの条件により、店頭で購入の意向が喚起され、商品を購入する購買行動 |
| （非計画購買）衝動購買 | 商品の新奇性や衝動により、商品を購入する購買行動                                                                     |
