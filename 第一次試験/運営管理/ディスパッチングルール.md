# ディスパッチングルール

- 待ちジョブの中から、次に処理するジョブを決めるための規則

## 代表的な規則

| ディスパッチングルール名                                      | 説明（特徴）                                                                                                                                |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 先着順規則<br />（First Come First Served Rule）              | 機械に先に到着したジョブを優先する規則                                                                                                      |
| 最小作業時間規則<br />（Shortest Processing Time First Rule） | 当該機械での加工時間が最小のジョブを優先する規則<br />（**平均滞留時間が最小となる**）                                                     |
| 最長作業時間規則<br />（Longest Processing Time First Rule）  | 当該機械での加工時間が最長のジョブを優先する規則                                                                                            |
| 最早納期規則<br />（Earliest Due-date First Rule）            | 納期が最も迫っているジョブを優先する規則<br />（**最大納期遅れが最小となる**）                                                             |
| 最小スラック規則<br />（Minimum Slack First Rule）            | 納期に対する余裕（スラック）が最小のジョブを優先する規則スラック：納期ー現在時間ー残り総加工時間<br />（**納期に対し前倒しに完成できる**） |

## 具体例

### 前提

* 現在時点は0日目で、機械は1台、すべてのジョブが待ち行列に入っている
* 各ジョブの到着順・加工時間・納期・残り総加工時間は次の通り

| ジョブ | 到着順 | 当該機械での加工時間 | 納期 | 残り総加工時間 | スラック |
| ------ | ------ | -------------------- | ---- | -------------- | -------- |
| A      | 1番目  | 6日                  | 12日 | 8日            | 4日      |
| B      | 2番目  | 2日                  | 8日  | 5日            | 3日      |
| C      | 3番目  | 4日                  | 10日 | 4日            | 6日      |
| D      | 4番目  | 3日                  | 7日  | 6日            | 1日      |

### 規則ごとの選択

* 先着順規則では、最も早く到着したAを選ぶ
* 最小作業時間規則では、加工時間が最短のBを選ぶ
* 最長作業時間規則では、加工時間が最長のAを選ぶ
* 最早納期規則では、納期が最も早いDを選ぶ
* 最小スラック規則では、スラックが最小のDを選ぶ

### 並べ替え例

| 規則                 | 処理順序             | 見るポイント             |
| -------------------- | -------------------- | ------------------------ |
| 先着順規則           | A → B → C → D        | 到着順                   |
| 最小作業時間規則     | B → D → C → A        | 当該機械での加工時間     |
| 最長作業時間規則     | A → C → D → B        | 当該機械での加工時間     |
| 最早納期規則         | D → B → C → A        | 納期                     |
| 最小スラック規則     | D → B → A → C        | 納期までの余裕           |
