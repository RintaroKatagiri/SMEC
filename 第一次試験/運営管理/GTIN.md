# GTIN（Global Trade Item Number）

- 「国際基準の商品識別コードの総称」と定義され、商品・サービスに対して設定するGS1基準の商品識別コード

## GTINの種類

| コード  | 内容                 | 桁数 | 主な用途・使われる場面                                                                   |
| ------- | -------------------- | :--: | ---------------------------------------------------------------------------------------- |
| GTIN-8  | JAN/EAN短縮コード    |  8   | 小型商品（ガム・鉛筆・口紅など）でバーコードを印刷するスペースが取れない場合に使用       |
| GTIN-12 | UPCコード            |  12  | 主に北米（アメリカ・カナダ）で流通する商品に使用。日本向け輸出入品で目にすることがある   |
| GTIN-13 | JAN/EAN標準コード    |  13  | 日本・ヨーロッパで最も一般的なバーコード。スーパーやコンビニで商品をスキャンする際のもの |
| GTIN-14 | 集合包装用商品コード |  14  | 段ボール箱などの集合包装（まとめ売り単位）に使用。倉庫・物流現場でのスキャン管理が目的   |

> **イメージ整理**
> - 消費者がレジでスキャンする → **GTIN-13**（または GTIN-8）
> - 物流倉庫で段ボール箱をスキャンする → **GTIN-14**
> - アメリカ製品を輸入した商品 → **GTIN-12**

### GTIN-13

#### 構成

- GS1事業者コード、商品アイテムコード、チェックデジットで構成される

##### GS1事業者コード

- GSI事業者コードの先頭の2桁は国コードであり、現在「49」と「45」が日本の国コード

### GTIN-14

#### 構成

- 先頭の1桁目はインジケータと呼ばれ、集合包装の荷姿や入数違い、販売促進の単位を分けることとなる
- インジケータの後には集合包装に内包される個装（単品）のGTIN-13の先頭12桁が表記され、最後の1桁がチェックデジットで、合計14桁
  - 末尾のチェックデジットは、内包されるGTIN-13のチェックデジットとは異なる数字になる

## GTIN認定ガイドライン

### 新しいGTINの設定が必要になる10の基準

|        | 内容                                                             | JANコード（単品・最小取引単位） | 商品包装用商品コード |
| ------ | ---------------------------------------------------------------- | :-----------------------------: | :------------------: |
| 基準1  | 新商品を販売した場合                                             |           新たに設定           |      新たに設定      |
| 基準2  | 商品表示の変更を伴う成分・機能を変更した場合                     |           新たに設定           |      新たに設定      |
| 基準3  | 商品表示の変更を伴う正味内容量を変更した場合                     |           新たに設定           |      新たに設定      |
| 基準4  | 包装の外寸、または総重量の20%以上を変更した場合                  |           新たに設定           |      新たに設定      |
| 基準5  | 認証マークを追加、または削除した場合                             |           新たに設定           |      新たに設定      |
| 基準6  | ブランドを変更した場合                                           |           新たに設定           |      新たに設定      |
| 基準7  | 販促のために期間限定で包装を変更、または景品・試供品を付けた場合 |            必要なし            |      新たに設定      |
| 基準8  | 集合包装の入数を変更した場合                                     |            必要なし            |      新たに設定      |
| 基準9  | セット内容や詰め合わせ商品の中身を変更した場合                   |           新たに設定           |      新たに設定      |
| 基準10 | 商品本体に表示された価格を変更した場合                           |           新たに設定           |      新たに設定      |

## キーワード

### インストアコード（インストアマーキング）

- GTIN（JANコード）が設定されていない商品に対して、事業者が社内管理のために、20~29（インストアマーキング用のプリフィックス：国コードにあたる部分）を先頭に用いて設定するコード
