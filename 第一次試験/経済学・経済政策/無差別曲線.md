# 無差別曲線

## 基本

- 無差別曲線とは、消費者に同じ効用を与える2財の消費量の組み合わせを結んだ曲線である
- 同じ無差別曲線上のすべての点では、効用水準は等しい
- 両方が望ましい財である通常のケースでは、右上にある無差別曲線ほど効用水準が高い

## 2財がともに望ましい財の場合

- 同じ効用水準を保つには、X財を増やすとY財を減らす必要があるため、無差別曲線は右下がりとなる
- 不完全代替財の無差別曲線は、原点に対して凸の曲線となる
    - 一方の財を多く持つほど、もう一方の財をさらに増やしても代わりに手放してよい量は小さくなるためである
- 完全代替財の無差別曲線は、右下がりの直線となる
    - 2財を常に一定の割合で代替できるため、限界代替率が一定である

| 2財の関係 | 無差別曲線の形状 |
| --- | --- |
| 不完全代替財 | 右下がり・原点に対して凸の曲線 |
| 完全代替財 | 右下がりの直線 |

## 望ましくない財を含む場合

- X財がお弁当のような望ましい財、Y財がゴミのような望ましくない財である場合を考える
- お弁当を増やすと効用は上昇し、ゴミを増やすと効用は低下する
- 同じ効用水準を保つには、ゴミが増えた分を補うため、お弁当も増やす必要がある
- したがって、この場合の無差別曲線は右上がりとなる

```text
ゴミを増やす（効用低下）
→ 同じ効用を保つには、お弁当を増やす必要がある
→ 無差別曲線は右上がり
```

- このケースでは、右下方向（お弁当が多く、ゴミが少ない方向）ほど効用水準が高くなる
- 右上がりの無差別曲線上でX財を1単位増やすとき、同じ効用水準を維持するためにはY財も増やさなければならない

## 試験の判断ポイント

- 同じ無差別曲線上の点 → 効用は同じ
- 不完全代替財 → 曲線
- 完全代替財 → 直線
- 望ましい財と望ましくない財の組み合わせ → 無差別曲線は右上がり
- 無差別曲線の「どちら側が高い効用か」は、各財が望ましい財か望ましくない財かで判断する
