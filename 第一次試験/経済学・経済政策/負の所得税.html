負の所得税（第21問）

凡例と公式

Yd = Y(1−t) + A
Y: 当初所得, t: 比例税率（0<t<1）
A: 定額給付（Y=0のときの可処分所得）
損益分岐点 Y₁ = A ÷ t（C と 45°線の交点）
■ 純給付領域: Y < Y₁ → Yd > Y
■ 純課税領域: Y > Y₁ → Yd < Y
D: 45°線（Yd = Y）
C: 直線（Yd = Y(1-t) + A、傾き 1-t < 1）
選択肢正誤理由
a: 0→Y₂で純給付増加誤Y₂>Y₁ → 課税領域、純給付はY₁で0→負
b: 0→Y₁でYd増加正C の傾き 1-t > 0 → Y↑→Yd↑
c: Y=Y₁でYd=Y正Y₁は損益分岐点 → C と 45°線の交点
d: Y=Y₃で追加所得に課税正Y₃>Y₁ → 純課税 → 追加所得に税率t適用
正答: オ（b と d）

a が誤りの理由: Y₂ は Y₁ の右（課税領域）→ Y₂ 時点では純給付は負（課税）
Y₁ = A/t = 損益分岐点 で純給付 = 0 → それ以上は課税
