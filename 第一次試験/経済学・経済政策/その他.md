# その他

## 財政の自動安定化装置（ビルドイン・スタビライザー）

- 景気変動に対して、政府がその都度政策を変更しなくても、税制や社会保障制度の仕組みによって総需要の変動を自動的に和らげる働き
- 代表例は、**所得税の累進課税、法人税、失業給付**などである

### 仕組み

#### 不況期

- 所得や企業利益が減少すると、所得税や法人税の負担が自動的に小さくなる
- 失業者が増えると、失業給付などの移転支出が自動的に増える
- 可処分所得の落ち込みが抑えられるため、消費や総需要の減少が緩和される

#### 好況期

- 所得や企業利益が増加すると、所得税や法人税の負担が自動的に大きくなる
- 失業者が減ると、失業給付などの移転支出が減る
- 可処分所得の増えすぎが抑えられるため、消費や総需要の過度な拡大が緩和される

### ポイント

- 景気が悪いときには景気を下支えし、景気が良いときには景気の過熱を抑える
- 政策決定を待たずに働くため、裁量的財政政策よりも発動の遅れが小さい
- 景気変動を完全になくすものではなく、変動幅を小さくする働きである
- 比例税率があるケインズ型モデルでは、所得が増えると税負担も増えるため、乗数効果を小さくする要因になる

### 試験での押さえ方

- 「自動」とは、個別の政策判断なしに制度として働くという意味である
- 不況期には、税収減少と移転支出増加によって財政赤字が拡大しやすい
- 好況期には、税収増加と移転支出減少によって財政収支が改善しやすい

## 情報の不完全性

### モラルハザード

* **定義**: 契約・取引の成立後に、情報の非対称性によって一方の当事者が相手に不利な行動をとる現象
* 「隠された行動（hidden action）」が原因。事後的な行動を観察・検証できないために生じる

#### 典型例

| 場面                 | 情報を持つ側（エージェント）               | 情報を持たない側（プリンシパル）     | 生じる問題                                     |
| -------------------- | ------------------------------------------ | ------------------------------------ | ---------------------------------------------- |
| 保険                 | 加入者                                     | 保険会社                             | 加入後に注意を怠る（過剰リスク行動）           |
| 労働契約             | 労働者（努力水準）                         | 雇用主                               | 監視できなければ手を抜く（サボり）             |
| 株式会社（経営委任） | 経営者                                     | 株主                                 | 株主の利益より自分の利益を優先（代理人問題）   |
| 金融機関             | 借り手                                     | 貸し手                               | 融資後に過剰リスク投資を行う                   |

#### 逆選択との違い

| 概念         | タイミング     | 原因                       | 例                                                   |
| ------------ | -------------- | -------------------------- | ---------------------------------------------------- |
| **逆選択**   | 契約・取引**前** | 隠された属性（hidden type） | 中古車市場でレモン（欠陥車）が集まる（アカロフ）     |
| **モラルハザード** | 契約・取引**後** | 隠された行動（hidden action） | 保険加入後に不注意になる                         |

#### 対処策

* **モニタリング（監視）**: 行動を直接観察・記録して情報の非対称を縮小する
* **インセンティブ設計**: 成果連動報酬（歩合給・ストックオプション）でエージェントの利益を委託者と一致させる
* **免責額・自己負担**: 保険の自己負担割合を設けることで被保険者の注意インセンティブを維持する
* **評判メカニズム**: 繰り返しゲームにより将来の評判を失うコストを行動の抑制力にする
* **スクリーニング・シグナリング**: 逆選択対策でもあるが、情報開示を義務付けることで事後的行動の余地を狭める

#### 試験での押さえ方

* モラルハザードは「情報の非対称性」×「事後」の問題
* プリンシパル＝エージェント問題（代理人問題）として出題されることが多い
* 対処策は「インセンティブの一致」か「情報の取得コスト低下」のいずれかに整理する
