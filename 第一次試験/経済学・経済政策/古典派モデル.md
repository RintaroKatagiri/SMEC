# 古典派モデル

## 古典派モデルの前提

* 価格・名目賃金は伸縮的に調整されると考える。
* 労働市場は常に均衡し、雇用量と実質GDPは完全雇用水準で決まる。
* したがって、実質GDPは `Y = YF` であり、貨幣量や物価の変化だけでは変わらない。これを**貨幣の中立性**という。
* 分析では、横軸を実質GDP `Y`、縦軸を物価水準 `P` とする。

```text
古典派では、実物面（雇用・実質GDP）は労働市場で決まる
→ 貨幣量の変化は、主に物価水準を変える
```

## 総需要曲線（AD）

### 貨幣需要とLM曲線

* 古典派では、貨幣需要として**取引需要**のみを想定し、利子率に依存する投機的需要を想定しない。
* したがって、貨幣市場の均衡は利子率ではなく、実質貨幣供給 `M/P` と実質GDP `Y` の対応で決まる。
* IS-LM図（横軸 `Y`、縦軸 `i`）では、LM曲線は**垂直**になる。

```text
物価水準 P が下落
→ 実質貨幣供給 M/P が増加
→ LM曲線が右へシフト
→ 利子率が低下
→ 投資が増加
→ 実質GDP Y が増加
```

* この関係を物価水準と実質GDPの図に写すと、古典派のAD曲線も**右下がり**になる。
* AD曲線上の移動では、`P↓` に対応して `Y↑`、`P↑` に対応して `Y↓` となる。

```text
   i                         P
   │  IS                     │\\ AD
   │     │ LM                │ \\
   │     │    LM'            │  \\
   │     ●                   │   \\
   │        ●                │
   └────────── Y             └──────── Y
      Y  →  Y'                  P↓ → Y↑
```

> ここでの「物価下落によるYの増加」は**AD曲線上の関係**である。実際の均衡GDPがどこで決まるかは、AS曲線との交点で判断する。

## 総供給曲線（AS）

* 古典派では名目賃金は下方にも伸縮的であるため、物価水準が下落すれば名目賃金も下落する。
* その結果、実質賃金 `W/P` は均衡水準に保たれ、労働市場の雇用量は完全雇用量 `L*` のままである。
* よって、実質GDPは常に完全雇用GDP `YF` であり、AS曲線は**垂直**になる。

```text
   P
   │        AS
   │        │
   │        │  物価が変わっても
   │        │  実質GDPは YF
   └────────┼──── Y
            YF
```

* 物価下落時も、名目賃金が同じ方向に調整されるので、実質賃金・雇用量・実質GDPは変化しない。
* 逆に物価上昇時も、名目賃金が上昇して実質賃金は均衡水準に保たれる。したがって、実質GDPは増えない。

## 財政政策と金融政策

### 拡張的財政政策：完全クラウディングアウト

* 政府支出の増加はIS曲線を右へシフトさせる。
* しかし古典派のLM曲線は垂直であるため、実質GDPは `YF` から増加できない。
* 利子率が上昇して民間投資が同額だけ減少する。これを**完全クラウディングアウト**という。
* 政府支出の増加分と民間投資の減少分が相殺されるので、総需要曲線は右へシフトしない。

```text
政府支出 G↑
→ IS曲線右シフト
→ 利子率 i↑
→ 民間投資 I↓（Gの増加分と同額）
→ 総需要は不変・実質GDPも YF のまま
```

### 拡張的金融政策：物価だけが上昇

* 貨幣供給量 `M` の増加は、実質貨幣供給を増やすため、AD曲線を右へシフトさせる。
* ただしAS曲線は `YF` で垂直なので、均衡は同じ `YF` 上を上方へ移るだけである。
* 結果は**物価水準の上昇**であり、実質GDP・雇用量は増加しない。

| 政策 | IS-LMでの主な動き | AD-ASでの結果 |
| --- | --- | --- |
| 拡張的財政政策（`G↑`） | IS右、`i↑`、民間投資が同額減少 | ADは不変、`Y=YF`、物価も不変 |
| 拡張的金融政策（`M↑`） | LM右、利子率低下圧力 | AD右、`Y=YF` のまま、`P↑` |

## 貨幣数量説

古典派の金融政策の結論は、貨幣数量説で確認できる。

```text
MV = PY

M：貨幣供給量
V：貨幣の流通速度
P：物価水準
Y：実質GDP
MV：1年間に取引に使用された貨幣の総額
PY：名目GDP
```

* 古典派では、`V` は一定、`Y` は完全雇用GDP `YF` で一定と考える。
* そのため `M` を増やしても、調整するのは `P` である。

```text
M↑（V・Yは一定）
→ P↑
→ 名目GDP PY は増えるが、実質GDP Y は増えない
```

### 試験での判定順序

1. 「古典派」とあれば、まず `AS` は垂直、実質GDPは `YF` と置く。
2. 財政政策なら、完全クラウディングアウトにより総需要は増えない。
3. 金融政策なら、ADは右へ動くが、増えるのは物価であって実質GDPではない。
4. `MV = PY` が示されたら、`V` と `Y` が一定かを確認し、貨幣量の増加が物価上昇につながると判断する。

## ケインズ派との対比

| 観点 | 古典派 | ケインズ派（通常のIS-LM） |
| --- | --- | --- |
| 貨幣需要 | 取引需要のみ | 取引需要・投機的需要 |
| LM曲線 | 垂直 | 右上がり |
| AS曲線 | 完全雇用GDPで垂直 | 短期には右上がりなどを想定 |
| 金融緩和 | 物価のみ上昇、実質GDPは不変 | 利子率低下・投資増加を通じて実質GDPを増やしうる |
| 財政拡張 | 完全クラウディングアウト | 一般に総需要を増やす（クラウディングアウトは一部） |
