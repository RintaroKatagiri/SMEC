# 自然失業率仮説

自然失業率仮説とは、古典派の流れを汲むマネタリストが提唱した説で、物価上昇率に関わらず、長期的には失業率が自然失業率に戻るという考え方である。

自然失業率とは、景気が特別に悪くも良くもないときに残る失業率である。転職活動中の失業や、産業構造の変化によって仕事の内容と労働者の技能が合わない失業などが含まれる。

```text
自然失業率
= 摩擦的失業や構造的失業など、長期的に残る失業率
```

## 短期と長期の違い

短期的には、政府や中央銀行が総需要を増やすと、生産や雇用が増え、失業率は自然失業率より低くなることがある。

```text
総需要増加
→ 生産増加
→ 雇用増加
→ 失業率低下
```

しかし、需要が増えて物価が上がり続けると、労働者や企業は「物価が上がるのが普通だ」と予想するようになる。労働者は物価上昇に見合う賃金上昇を求め、企業の費用も上がる。その結果、雇用を増やす効果は弱まり、失業率は自然失業率に戻る。

```text
物価上昇
→ 期待インフレ率上昇
→ 賃金上昇
→ 企業の費用増加
→ 雇用増加の効果が弱まる
→ 失業率は自然失業率へ戻る
```

### フィリップス曲線との関係

短期のフィリップス曲線では、インフレ率と失業率の間にトレードオフがあると考える。

```text
インフレ率上昇 → 失業率低下
インフレ率低下 → 失業率上昇
```

自然失業率仮説では、このトレードオフは短期的なものにすぎないと考える。長期的には、期待インフレ率が調整されるため、失業率は自然失業率に戻る。したがって、長期フィリップス曲線は自然失業率の位置で垂直になる。

### 貨幣錯覚が生む短期のトレードオフ

自然失業率仮説では、短期には労働者が物価水準の上昇をすぐには正確に認識しないという**貨幣錯覚**を置く。

```text
予想を上回る物価上昇
→ 名目賃金 W が上昇
→ 労働者は P の上昇を十分に織り込めず、実質賃金 W/P が上がったと錯覚
→ 労働供給を増やす
→ 雇用量が増加し、失業率は自然失業率 UN より低下
```

* このため、短期フィリップス曲線は右下がりになる。インフレ率が上がるほど失業率が下がるように見える。
* ただし原因は、**予想外の**物価上昇である。予想どおりの物価上昇だけでは、労働者は実質賃金が上がったと錯覚しない。

### 期待で調整されたフィリップス曲線

短期フィリップス曲線は、期待インフレ率を含めて次のように表せる。

```text
π = πe − α(u − uN)  （α > 0）

π  ：実際のインフレ率
πe ：期待インフレ率
u  ：実際の失業率
uN ：自然失業率
```

* `u = uN` のとき、`π = πe` となる。実際のインフレ率と期待インフレ率が一致し、失業率は自然失業率にある。
* `u < uN` のとき、`π > πe` となる。予想を上回るインフレによって、短期的に失業率が自然失業率を下回っている。
* `u > uN` のとき、`π < πe` となる。実際のインフレ率が期待より低く、失業率は自然失業率を上回る。

期待インフレ率が上昇すると、同じ失業率でもより高い実際のインフレ率が必要になるため、短期フィリップス曲線は**上方へ平行移動**する。

```text
短期：予想外のインフレ率上昇 → 曲線に沿って左上へ → u は一時的に低下
長期：期待インフレ率上昇     → 短期フィリップス曲線が上方へシフト
      → u は uN に戻るが、インフレ率はより高い水準になる
```

### 長期フィリップス曲線の読み方

```text
物価上昇率 π
↑
│          │ 長期フィリップス曲線
│       ／ │
│    ／    │
│ ／       │
└─────────┼──→ 失業率 u
          uN
```

* 長期フィリップス曲線は、自然失業率 `uN` で垂直である。
* したがって、長期ではインフレ率をどの水準にしても、失業率を `uN` より低く維持することはできない。
* 試験では、**「短期にはトレードオフあり、長期にはトレードオフなし」**と整理する。

## 政策への含意

政府や中央銀行が総需要を増やしても、長期的に失業率を自然失業率より低く保つことはできない。無理に失業率を下げ続けようとすると、期待インフレ率が上がり、より高いインフレを招きやすくなる。

長期的に自然失業率を下げるには、単に総需要を増やすのではなく、労働市場の構造を改善する必要がある。

例として、次のような政策が考えられる。

- 職業訓練によって技能のミスマッチを小さくする
- 求人情報や職業紹介を充実させ、転職にかかる時間を短くする
- 労働移動をしやすくし、成長産業へ人が移りやすくする

## 試験での押さえ方

- 短期では、インフレ率上昇により失業率が下がることがある
- 長期では、期待インフレ率が調整され、失業率は自然失業率に戻る
- 長期フィリップス曲線は、自然失業率の位置で垂直になる
- 総需要政策だけでは、長期的に自然失業率を下回る失業率を維持できない
- 自然失業率を下げるには、労働市場の構造改善が必要である
