# 自然失業率仮説

自然失業率仮説とは、古典派の流れを汲むマネタリストが提唱した説で、物価上昇率に関わらず、長期的には失業率が自然失業率に戻るという考え方である。

自然失業率とは、景気が特別に悪くも良くもないときに残る失業率である。転職活動中の失業や、産業構造の変化によって仕事の内容と労働者の技能が合わない失業などが含まれる。

```text
自然失業率
= 摩擦的失業や構造的失業など、長期的に残る失業率
```

## 短期と長期の違い

短期的には、政府や中央銀行が総需要を増やすと、生産や雇用が増え、失業率は自然失業率より低くなることがある。

```text
総需要増加
→ 生産増加
→ 雇用増加
→ 失業率低下
```

しかし、需要が増えて物価が上がり続けると、労働者や企業は「物価が上がるのが普通だ」と予想するようになる。労働者は物価上昇に見合う賃金上昇を求め、企業の費用も上がる。その結果、雇用を増やす効果は弱まり、失業率は自然失業率に戻る。

```text
物価上昇
→ 期待インフレ率上昇
→ 賃金上昇
→ 企業の費用増加
→ 雇用増加の効果が弱まる
→ 失業率は自然失業率へ戻る
```

### フィリップス曲線との関係

短期のフィリップス曲線では、インフレ率と失業率の間にトレードオフがあると考える。

```text
インフレ率上昇 → 失業率低下
インフレ率低下 → 失業率上昇
```

自然失業率仮説では、このトレードオフは短期的なものにすぎないと考える。長期的には、期待インフレ率が調整されるため、失業率は自然失業率に戻る。したがって、長期フィリップス曲線は自然失業率の位置で垂直になる。

## 政策への含意

政府や中央銀行が総需要を増やしても、長期的に失業率を自然失業率より低く保つことはできない。無理に失業率を下げ続けようとすると、期待インフレ率が上がり、より高いインフレを招きやすくなる。

長期的に自然失業率を下げるには、単に総需要を増やすのではなく、労働市場の構造を改善する必要がある。

例として、次のような政策が考えられる。

- 職業訓練によって技能のミスマッチを小さくする
- 求人情報や職業紹介を充実させ、転職にかかる時間を短くする
- 労働移動をしやすくし、成長産業へ人が移りやすくする

## 試験での押さえ方

- 短期では、インフレ率上昇により失業率が下がることがある
- 長期では、期待インフレ率が調整され、失業率は自然失業率に戻る
- 長期フィリップス曲線は、自然失業率の位置で垂直になる
- 総需要政策だけでは、長期的に自然失業率を下回る失業率を維持できない
- 自然失業率を下げるには、労働市場の構造改善が必要である
