# マンデル・フレミングモデル

## 基本

- 開放経済におけるIS-LMモデル
- 財市場、貨幣市場、国際収支の均衡を同時に考える
- 財政政策や金融政策の効果が、為替相場制度によってどう変わるかを見るモデル

## IS-LMモデルの位置づけ

IS-LMモデルは、閉鎖経済の短期的な均衡を、財市場と貨幣市場から考えるモデルである。横軸に国民所得 `Y`、縦軸に利子率 `i` をとる。

- IS曲線は、財市場が均衡する `Y` と `i` の組み合わせを表す
- LM曲線は、貨幣市場が均衡する `Y` と `i` の組み合わせを表す
- IS曲線とLM曲線の交点が、財市場と貨幣市場が同時に均衡する国民所得と利子率になる

IS曲線は右下がりである。利子率が下がると企業の投資が増えやすくなり、総需要が増えて国民所得が増えるためである。

```text
利子率低下 → 投資増加 → 総需要増加 → 国民所得増加
```

LM曲線は右上がりである。国民所得が増えると取引に必要な貨幣需要が増え、貨幣市場を均衡させるためには利子率が上がる必要があるためである。

```text
国民所得増加 → 貨幣需要増加 → 利子率上昇
```

政策の効果は、IS曲線またはLM曲線のシフトとして考える。（横軸：国民所得　縦軸：利子率）

| 政策     | 動く曲線           | 直感                                           |
| -------- | ------------------ | ---------------------------------------------- |
| 財政拡張 | IS曲線が右にシフト | 政府支出の増加などにより総需要が増える         |
| 金融緩和 | LM曲線が右にシフト | 貨幣供給量の増加により利子率が下がりやすくなる |

## 財政拡張と金融緩和

### 財政拡張

財政拡張とは、政府が支出を増やしたり減税したりして、景気を良くしようとする政策である。政府支出の増加は、政府自身が財やサービスを買うため、総需要を直接増やす。減税は、家計や企業が使えるお金を増やし、消費や投資を増やしやすくする。

IS-LMモデルでは、財政拡張は財市場に最初に影響する。そのため、IS曲線が右にシフトする。

```text
政府支出増加・減税
→ 総需要増加
→ IS曲線が右にシフト
→ 国民所得増加
→ 貨幣需要増加
→ 利子率上昇
```

閉鎖経済のIS-LMモデルでは、財政拡張により国民所得は増え、利子率は上がりやすい。ただし、利子率が上がると民間投資が減りやすくなるため、政府支出の増加分がすべて国民所得の増加になるわけではない。このように、利子率上昇によって民間投資が押し出されることをクラウディングアウトという。

マンデル・フレミングモデルでは、この利子率上昇が資本流入と自国通貨高圧力につながる。したがって、財政拡張の効果は、為替相場制度によって変わる。

### 金融緩和

金融緩和とは、中央銀行が貨幣供給量を増やしたり政策金利を下げたりして、景気を良くしようとする政策である。世の中に出回るお金が増えると、お金を借りやすくなり、企業の投資や家計の消費が増えやすくなる。

IS-LMモデルでは、金融緩和は貨幣市場に最初に影響する。そのため、LM曲線が右にシフトする。

```text
貨幣供給量増加
→ LM曲線が右にシフト
→ 利子率低下
→ 投資増加
→ 総需要増加
→ 国民所得増加
```

閉鎖経済のIS-LMモデルでは、金融緩和により利子率は下がり、国民所得は増えやすい。利子率が下がると、企業は資金調達をしやすくなり、設備投資を増やしやすくなるためである。

マンデル・フレミングモデルでは、この利子率低下が資本流出と自国通貨安圧力につながる。したがって、金融緩和の効果も、為替相場制度によって変わる。

マンデル・フレミングモデルは、このIS-LMモデルに「外国との取引」と「為替レート」を加えた開放経済版のモデルである。そのため、IS曲線やLM曲線の動きだけでなく、資本移動、為替レート、純輸出の変化まで合わせて考える。

## 概要

マンデル・フレミングモデルは、簡単にいうと「外国とお金のやり取りをしている国では、政府や中央銀行の政策が、為替レートを通じて効き方を変える」という話である。

ポイントは次の3つである。

- お金は、利子率が高い国に集まりやすい
- 自国通貨安になると、輸出が増えやすい
- 自国通貨高になると、輸出が減りやすい

例えば、日本の利子率が外国より高くなると、外国の投資家は「日本で運用した方が得だ」と考え、日本にお金を移す。このとき円を買う動きが増えるため、円高になりやすい。

反対に、日本の利子率が外国より低くなると、お金が外国に出ていきやすくなる。このとき円を売る動きが増えるため、円安になりやすい。

```text
利子率が高い国 → お金が集まる → その国の通貨が高くなりやすい
利子率が低い国 → お金が出ていく → その国の通貨が安くなりやすい
```

## まず覚える結論

試験では、まず次の表を覚える。

| 為替相場制度 | 金融政策 | 財政政策 |
| ------------ | -------- | -------- |
| 変動相場制   | 有効     | 無効     |
| 固定相場制   | 無効     | 有効     |

かなり単純化すると、次のように考える。

- 変動相場制では、為替レートが動けるので、金融政策が効きやすい
- 固定相場制では、為替レートを固定するために中央銀行が動くので、財政政策が効きやすい

## 前提

試験では、次の前提で考えることが多い。

- 小国開放経済
- 資本移動が完全
- 国内利子率 `i` は世界利子率 `i*` に一致する
- 国際収支は、経常収支と資本収支で決まる

資本移動が完全な場合、国内利子率が世界利子率から少しでもずれると、資本移動が起こる。

| 状態       | 資本移動 | 為替への圧力   |
| ---------- | -------- | -------------- |
| `i > i*` | 資本流入 | 自国通貨高圧力 |
| `i < i*` | 資本流出 | 自国通貨安圧力 |

## 4パターンの直感

### 変動相場制で金融緩和をする場合

金融緩和とは、世の中に出回るお金を増やして、利子率を下げようとする政策である。

```text
金融緩和
→ 利子率が下がる
→ お金が外国へ出ていく
→ 自国通貨安になる
→ 輸出が増える
→ 景気が良くなる
```

変動相場制では為替レートが自由に動くため、自国通貨安を通じて金融政策が効く。

### 変動相場制で財政拡張をする場合

財政拡張とは、政府支出を増やして、景気を良くしようとする政策である。

```text
財政拡張
→ 景気が良くなり、利子率が上がる
→ お金が国内に入ってくる
→ 自国通貨高になる
→ 輸出が減る
→ 財政政策の効果が弱まる
```

変動相場制では、財政政策で景気を良くしようとしても、自国通貨高による輸出減少で効果が打ち消されやすい。

### 固定相場制で金融緩和をする場合

固定相場制では、為替レートを一定に保つ必要がある。

```text
金融緩和
→ 利子率が下がる
→ お金が外国へ出ていく
→ 自国通貨安になりそうになる
→ 中央銀行が自国通貨を買って支える
→ 世の中のお金が減る
→ 金融緩和が打ち消される
```

固定相場制では、為替レートを守るための介入によって金融政策の効果が消えやすい。

### 固定相場制で財政拡張をする場合

```text
財政拡張
→ 景気が良くなり、利子率が上がる
→ お金が国内に入ってくる
→ 自国通貨高になりそうになる
→ 中央銀行が自国通貨を売る
→ 世の中のお金が増える
→ さらに景気が良くなる
```

固定相場制では、為替レートを守るための介入が、結果的に財政政策を後押しする。

## 変動相場制

変動相場制では、為替レートが市場で変化する。中央銀行は為替レートを固定するための介入を行わない。

### 金融政策

金融緩和により貨幣供給量が増えると、LM曲線が右にシフトし、国内利子率が低下する。

```text
金融緩和
→ 利子率低下
→ 資本流出
→ 自国通貨安
→ 輸出増加・輸入減少
→ 純輸出増加
→ 国民所得増加
```

したがって、変動相場制では金融政策は有効である。

### 財政政策

政府支出の増加などによりIS曲線が右にシフトすると、国内利子率が上昇する。

```text
財政拡張
→ 利子率上昇
→ 資本流入
→ 自国通貨高
→ 輸出減少・輸入増加
→ 純輸出減少
→ 財政政策の効果が打ち消される
```

したがって、完全資本移動の変動相場制では財政政策は無効である。

## 固定相場制

固定相場制では、中央銀行が為替レートを一定に保つために為替介入を行う。その結果、貨幣供給量が内生的に変化する。

### 金融政策

金融緩和により貨幣供給量が増えると、国内利子率が低下し、自国通貨安圧力が生じる。

```text
金融緩和
→ 利子率低下
→ 資本流出
→ 自国通貨安圧力
→ 中央銀行が自国通貨を買う
→ 貨幣供給量が減少
→ 金融緩和の効果が打ち消される
```

したがって、固定相場制では金融政策は無効である。

### 財政政策

政府支出の増加などによりIS曲線が右にシフトすると、国内利子率が上昇し、自国通貨高圧力が生じる。

```text
財政拡張
→ 利子率上昇
→ 資本流入
→ 自国通貨高圧力
→ 中央銀行が自国通貨を売る
→ 貨幣供給量が増加
→ LM曲線が右にシフト
→ 国民所得増加
```

したがって、固定相場制では財政政策は有効である。

## 政策効果のまとめ

| 為替相場制度 | 金融政策 | 財政政策 |
| ------------ | -------- | -------- |
| 変動相場制   | 有効     | 無効     |
| 固定相場制   | 無効     | 有効     |

覚え方は次のとおり。

- 変動相場制では、金融政策が為替レートを通じて効く
- 固定相場制では、財政政策が為替介入による貨幣供給量の変化を伴って効く

## 為替レートとの関係

自国通貨安になると、外国から見た自国財が安くなるため輸出が増えやすい。また、自国から見た外国財が高くなるため輸入が減りやすい。

```text
自国通貨安 → 輸出増加・輸入減少 → 純輸出増加 → IS曲線が右にシフト
```

自国通貨高になると、外国から見た自国財が高くなるため輸出が減りやすい。また、自国から見た外国財が安くなるため輸入が増えやすい。

```text
自国通貨高 → 輸出減少・輸入増加 → 純輸出減少 → IS曲線が左にシフト
```

## よくあるひっかけ

- 固定相場制では、中央銀行が為替レートを維持するため、貨幣供給量を自由に決めにくい
- 変動相場制では、為替レートが調整するため、財政政策の効果が純輸出の変化で打ち消されやすい
- 「財政政策はいつでも有効」「金融政策はいつでも有効」と考えない
- 完全資本移動を前提にしている場合の結論である
- 資本移動が不完全な場合は、政策効果が部分的に残ることがある

## 試験での押さえ方

- 変動相場制では、金融政策が有効、財政政策は無効
- 固定相場制では、財政政策が有効、金融政策は無効
- 利子率が上がると資本流入、自国通貨高圧力
- 利子率が下がると資本流出、自国通貨安圧力
- 自国通貨安は純輸出を増やし、自国通貨高は純輸出を減らす
