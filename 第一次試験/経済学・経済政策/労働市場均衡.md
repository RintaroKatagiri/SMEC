## 労働市場均衡（第20問）★重要★

### 労働市場の基本構造

グラフは → [労働市場.html](労働市場.html)

```
賃金率
↑A
W₀────────E（均衡: D∩S）
B                  S（労働供給）
          D（労働需要）
──────────────────→ 労働量
O         N₀
```

* **D（労働需要曲線）**: 企業の限界収入生産（MRP = 価格 × 限界生産物）← 右下がり
* **S（労働供給曲線）**: 労働者の労働供給意欲 ← 右上がり
* **均衡点 E**: D ∩ S → 均衡賃金 W₀、均衡雇用量 N₀

### 均衡賃金を上昇させる要因（設問1 a〜d）

均衡賃金 W₀ の上昇 ← **D シフト右（需要増）** または **S シフト左（供給減）**

| 選択肢 | 内容 | シフト方向 | 賃金への影響 |
|--------|------|-----------|------------|
| a | 労働と補完的な生産技術水準の向上 | D 右シフト（MRP 上昇） | **賃金↑** |
| b | 雇用環境の改善に伴う労働の限界不効用の低下 | S 右シフト（労働供給増） | 賃金↓ |
| c | 企業による資本投入量の増加 | D 右シフト（労働の MRP 上昇） | **賃金↑** |
| d | 出生率の上昇に伴う生産年齢人口の増加 | S 右シフト（労働供給増） | 賃金↓ |

**→ 設問1 正答: ア（a と c）**

### 余剰の領域（設問2 a〜d）★重要★

| 概念 | 定義 | グラフ上の領域 |
|------|------|--------------|
| **労働者余剰（消費者余剰相当）** | 労働者が受け取る賃金 − 留保賃金の合計 | **三角形 AW₀E**（W₀ より上、S 曲線より左） |
| **企業余剰（生産者余剰相当）** | 企業が支払う最大賃金 − 実際の賃金の合計 | **三角形 W₀BE** (W₀ より下、D 曲線より左) |
| **労働者の機会費用** | 就業しなかった場合の代替的な収入（留保賃金の合計） | **三角形 AON₀E**（供給曲線下の面積）または 四角形 AON₀E |
| **企業の労働費用** | 均衡賃金 × 雇用量 | **四角形 W₀ON₀E** |

### 各選択肢の正誤（設問2 a〜d）

| 選択肢 | 記述 | 正誤 | 理由 |
|--------|------|------|------|
| a | 労働者余剰は三角形 AW₀E | **正** | 需要曲線（A から W₀） と W₀ の差 = 三角形 AW₀E |
| b | 労働者の機会費用は四角形 AON₀E | **正** | 供給曲線下の面積（S 曲線 0 から N₀） = 四角形 AON₀E ※直線なら台形 |
| c | 企業の労働費用は四角形 W₀ON₀E | **正** | W₀ × N₀ = 四角形 W₀ON₀E |
| d | 企業余剰は三角形 AW₀E | **誤** | 三角形 AW₀E は**労働者余剰**。企業余剰は三角形 W₀BE |

**→ 設問2 正答: ア（a と b）**

### 労働需要をシフトさせる要因

* 右シフト（需要増 → 賃金上昇・雇用増）
  → 生産物価格の上昇、技術進歩（労働と補完的）、資本投入量の増加
* 左シフト（需要減 → 賃金低下・雇用減）
  → 生産物需要の減少、省力化技術（労働代替）

### 労働供給をシフトさせる要因

* 右シフト（供給増 → 賃金低下・雇用増）
  → 人口増加、移民流入、労働の限界不効用の低下（楽な仕事）
* 左シフト（供給減 → 賃金上昇・雇用減）
  → 高齢化、少子化、労働環境悪化
