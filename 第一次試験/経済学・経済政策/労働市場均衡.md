# 労働市場均衡

## 労働市場の基本構造

グラフは → [労働市場.html](労働市場.html)

```
賃金率
↑A
W₀────────E（均衡: D∩S）
B                  S（労働供給）
          D（労働需要）
──────────────────→ 労働量（企業が雇う労働の量）
O         N₀
```

### 労働需要曲線

- 企業の限界収入生産（MRP = 価格 × 限界生産物）← 右下がり
  - 賃金が高いほど、企業が雇いたい労働者数は少なくなるから

```
賃金が高い
→ 高い価値を生む労働者までしか雇えない
→ 雇用量は少ない

賃金が低い
→ 生産性が低めの追加労働者も雇える
→ 雇用量は多い
```

### 労働供給曲線

- 労働者の労働供給意欲 ← 右上がり

* **均衡点 E**: D ∩ S → 均衡賃金 W₀、均衡雇用量 N₀

## 均衡賃金を上昇させる要因

均衡賃金 W₀ の上昇 ← **D シフト右（需要増）** または **S シフト左（供給減）**

|                    内容                    |                                                        シフト方向                                                        |   賃金への影響   |
| :----------------------------------------: | :----------------------------------------------------------------------------------------------------------------------: | :--------------: |
|      労働と補完的な生産技術水準の向上      | D 右シフト（MRP 上昇）<br />（∵補完的なので、仕事が奪われるのではなく、一人当たりの生産性が上がるため労働者を欲しがる） | **賃金↑** |
| 雇用環境の改善に伴う労働の限界不効用の低下 |   S 右シフト（労働供給増）<br />（∵限界不効用とはしんどさのことであり、それが低下すると同じ賃金で働きたい人が増える）   |      賃金↓      |
|         企業による資本投入量の増加         |           D 右シフト（労働の MRP 上昇）<br />（∵資本投入が増えると、労働者1人あたりが生み出せる価値が上がる）           | **賃金↑** |
|    出生率の上昇に伴う生産年齢人口の増加    |                             S 右シフト（労働供給増）<br />（∵同じ賃金で働きたい人が増える）                             |      賃金↓      |

## 余剰の領域

労働市場では、企業が労働を「買う側」、労働者が労働を「売る側」になる。

そのため、通常の財市場との対応は次のようになる。

```text
企業余剰   = 消費者余剰に相当（労働を買う側の得）
労働者余剰 = 生産者余剰に相当（労働を売る側の得）
```

| 概念                                   | 定義                                   | グラフ上の領域                                       |
| -------------------------------------- | -------------------------------------- | ---------------------------------------------------- |
| **労働者余剰（生産者余剰相当）** | 実際の賃金 − 留保賃金の合計           | **賃金線 W₀ の下、供給曲線 S の上**（0〜N₀） |
| **企業余剰（消費者余剰相当）**   | 企業が支払ってもよい賃金 − 実際の賃金 | **需要曲線 D の下、賃金線 W₀ の上**（0〜N₀） |
| **労働者の機会費用**             | 労働者が働くためにあきらめた価値の合計 | **供給曲線 S の下の面積**（0〜N₀）            |
| **企業の労働費用**               | 均衡賃金 × 雇用量                     | **四角形 W₀ON₀E**                            |

上の簡略図で、需要曲線 `D` が縦軸の `A` から均衡点 `E` に向かう線、供給曲線 `S` が縦軸の `B` から均衡点 `E` に向かう線だと読むなら、

```text
企業余剰   = 三角形 A-W₀-E
労働者余剰 = 三角形 B-W₀-E
```

となる。元の表のように、労働者余剰を `A-W₀-E`、企業余剰を `W₀-B-E` とすると逆になる。

## 労働需要をシフトさせる要因

* 右シフト（需要増 → 賃金上昇・雇用増）
  → 生産物価格の上昇、技術進歩（労働と補完的）、資本投入量の増加
* 左シフト（需要減 → 賃金低下・雇用減）
  → 生産物需要の減少、省力化技術（労働代替）

## 労働供給をシフトさせる要因

* 右シフト（供給増 → 賃金低下・雇用増）
  → 人口増加、移民流入、労働の限界不効用の低下（楽な仕事）
* 左シフト（供給減 → 賃金上昇・雇用減）
  → 高齢化、少子化、労働環境悪化

## 需要独占

- 労働市場において、需要者は企業であり、供給者は家計である
- 地域で生産活動を行う企業（需要者）が1社のみの場合、供給者（家計）はその企業に勤めるしかないため、企業は賃金を低く抑えることが出来る
- このような企業が利潤を最大化するためには、追加的に発生する労働によって得られる収入と費用を一致する基準に雇用量を決定することとなる

## 雇用・失業統計

### 15歳以上人口の区分

```text
15歳以上人口
├─ 労働力人口
│  ├─ 就業者
│  │  ├─ 従業者
│  │  └─ 休業者
│  └─ 完全失業者
└─ 非労働力人口
   ├─ 通学
   ├─ 家事
   └─ その他（高齢者など）
```

- 労働力人口とは、15歳以上人口のうち、就業者と完全失業者を合わせたものである
- 非労働力人口とは、15歳以上人口のうち、労働力人口以外の者である
    - 専業主婦・専業主夫は、就業者でも完全失業者でもないため、非労働力人口に含まれる
- 就業者とは、従業者と休業者を合わせたものである
- 従業者とは、調査期間中に収入を伴う仕事を1時間以上した者である
- 休業者とは、調査期間中に仕事を持ちながら、少しも仕事をしなかった一定の者である

### 完全失業者の条件

- 完全失業者とは、次の3条件をすべて満たす者である
    1. 調査期間中に仕事がなく、少しも仕事をしなかった者
    2. 調査期間中に求職活動をしていた者
    3. 仕事があれば、すぐに就くことができる者
- 仕事をしておらず、求職活動もしていない者は、完全失業者ではなく非労働力人口に分類される

### 失業率と有効求人倍率

- 完全失業率は、労働力人口に占める完全失業者の割合である

$$
完全失業率 = \frac{完全失業者数}{労働力人口} \times 100
$$

- 有効求人倍率は、月間有効求人数を月間有効求職者数で割った値である

$$
有効求人倍率 = \frac{月間有効求人数}{月間有効求職者数}
$$

- 有効求人倍率が1を超えても、企業が求める能力と求職者の能力が合わない求人・求職のミスマッチなどにより、完全失業率がゼロになるとは限らない
- 労働力人口は15歳以上人口を対象とするため、15歳以上の未成年者も含まれる

### 失業の種類と完全雇用

- 賃金が伸縮的である古典派モデルでは、現行の賃金で働くことを希望しているにもかかわらず就業できない非自発的失業は存在せず、完全雇用が実現すると考える
- 完全雇用とは、非自発的失業が存在しない状態であり、完全失業率がゼロであることを意味しない

| 種類 | 内容 | 完全雇用時の扱い |
| --- | --- | --- |
| 摩擦的失業 | 転職・就職活動の途中に不可避的に生じる失業 | 発生する |
| 構造的失業 | 産業構造の変化や技能のミスマッチなど、経済構造に関する要因による失業 | 発生する |
| 自発的失業 | 労働者が現行の賃金では働かないことを選択するために生じる失業 | 発生する |
| 循環的失業 | 景気循環に伴って生じる失業。不況時の雇用調整などによる失業 | 発生しない |

- 循環的失業は、総需要の不足によって生じるため、需要不足失業ともいう
- 摩擦的失業や構造的失業は、完全雇用が実現している状態でも発生する
- したがって、完全雇用の状態でも完全失業率はゼロとは限らない

## 価格・賃金の硬直性

- 価格・賃金の硬直性とは、価格や賃金が変化しにくい性質をいう
- 賃金の下方硬直性とは、名目賃金が低下しにくい性質をいう
- ケインズ理論では、名目賃金に下方硬直性があるため、非自発的失業が生じうると考える

### メニュー・コスト

- メニュー・コストとは、価格や賃金を改定する際にかかる費用をいう
    - 例：価格表・メニューの作り直し、システム変更、顧客への周知にかかる費用
- メニュー・コストが大きいほど価格改定を避けやすく、価格の硬直性の要因となる
- 多様な価格設定を用意すると、改定する価格の種類が増えてメニュー・コストが大きくなるため、価格は硬直的になりやすい
- 反対に、メニュー・コストを引き下げると価格改定がしやすくなるため、価格の硬直性は弱まる

### 効率賃金

- 効率賃金とは、労働市場の需要と供給で決まる均衡賃金よりも高い賃金を支払う考え方である
- 効率賃金を支払うことで、労働者の働く意欲や生産性が高まると考える
- 企業は士気や生産性の低下を避けるために賃金を引き下げにくくなり、賃金の下方硬直性の要因となる

### 実質賃金の下方硬直性

- 実質賃金は、名目賃金を物価で割って求める

$$
実質賃金 = \frac{W}{P}
$$

- $W$ は名目賃金、$P$ は物価水準を表す
- 物価よりも名目賃金が下方硬直的である場合、物価が下落しても名目賃金が十分に下がらないため、実質賃金は低下しにくい

```text
名目賃金よりも物価が大きく低下する
→ W / P は上昇しやすい
→ 実質賃金は下方硬直的
```

- 反対に、物価の方が名目賃金より下方硬直的であれば、実質賃金は低下しやすい
