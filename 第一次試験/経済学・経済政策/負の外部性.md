## 負の外部性

### 外部性とは

* 市場取引を通じずに第三者へ影響を与える現象
* **外部経済（正の外部性）**: 第三者に便益 → 社会的便益 > 私的便益 → 過小生産
* **外部不経済（負の外部性）**: 第三者に損害 → 社会的費用 > 私的費用（or 社会的便益 < 私的便益）→ **過大消費**
  * 政策や制度によって供給量が減少するものをイメージする
    * 二酸化炭素の排出量を基準とした化石燃料への課税など

### 第18問の設定（観光資源の負の外部性）

* 観光客増加 → 交通渋滞・ゴミ → **近隣住民への損害**（負の外部性）
* 私的限界価値曲線: **Db**（消費者の支払意欲）
* 社会的限界価値曲線: **D₁**（Db より下方 ← 外部不経済の分だけ社会的価値が低い）
* 供給曲線: **S**

### 均衡の比較

| 均衡                   | 数量     | 特徴                                         |
| ---------------------- | -------- | -------------------------------------------- |
| **完全競争均衡** | S ∩ Db  | **過大消費**（外部不経済を考慮しない） |
| **社会的最適**   | S ∩ D₁ | 外部不経済を内部化した最適量（< 完全競争量） |

### 余剰・死荷重の各領域（第18問 a〜d）

グラフ上の点（上から）:

* C: 価格軸切片（Db の最大価格）
* A: S ∩ Db の価格（完全競争均衡価格）
* G: 完全競争均衡点（Db 上）
* E: Db 上（社会最適量での Db の価格）
* F: D₁ 上（社会最適量での D₁ の価格）
* H: S 上（社会最適量での供給価格）
* S: 社会最適均衡点（D₁ 上）
* B: 価格軸切片（D₁ の最大価格）

| 選択肢                                      | 正誤         | 理由                                                                    |
| ------------------------------------------- | ------------ | ----------------------------------------------------------------------- |
| a: 完全競争均衡の死荷重 = 四角形 GFHE       | **誤** | 死荷重は**三角形**（過大消費による余剰損失）≠ 四角形             |

### 政策対応

| 手段                     | 内容                                                        |
| ------------------------ | ----------------------------------------------------------- |
| **ピグー税**       | 外部不経済の大きさに等しい税を課す → 私的費用 = 社会的費用 |
| 規制                     | 消費・生産の上限規制                                        |
| 補助金（外部経済の場合） | 過小生産を補正                                              |
| コース定理               | 取引費用ゼロなら当事者交渉で外部性を内部化可能              |

### 観光資源の具体例（第18問）

* 外部不経済: 観光客増加 → 渋滞・ゴミ → 近隣住民の損害
* Db（私的）> D₁（社会的）: 観光客は渋滞コストを負担しない
* 完全競争市場では過大な観光消費が発生

### 生産側の外部不経済（費用曲線でとらえるケース）

* 上記の観光資源の例は「需要（価値）曲線」側で外部不経済をとらえるケースだが、工場排煙のように「供給（費用）曲線」側で外部不経済をとらえるケースもよく出題される
* 私的限界費用（PMC）: 生産者自身が負担する費用のみを反映した限界費用曲線
* 社会的限界費用（SMC）: 私的限界費用に、第三者への損害（外部費用）を加えた限界費用曲線
* 外部不経済が存在する場合、生産者は損害分を負担していないため **PMC は SMC より下方に位置する**
* 需要曲線（D）との交点で見ると
  * 完全競争均衡: D ∩ PMC → 過大生産
  * 社会的最適: D ∩ SMC（< 完全競争均衡の数量）
* ピグー税は、この PMC と SMC の差（外部費用分）に等しい税を生産者に課すことで、PMC を SMC に一致させ、社会的最適な生産量を実現する政策手段
  * 「補助金」ではなく「課税」による対応である点に注意（外部経済＝正の外部性の場合は逆に補助金で対応）
* コースの定理は、あくまで「取引費用がゼロ」であることを前提とした場合に、当事者間の自発的交渉により外部性が内部化されうるとする命題であり、取引費用が存在する現実の状況では必ずしも内部化されるとは限らない
