# 等費用線と等産出量曲線

## 等費用線（Isocost）

- 費用が等しくなる資本投入量と労働投入量の組み合わせを結んだものであり、右肩下がりの直線となる
  - 総費用を一定にしたままで片方を増やすともう片方は減少する

* 同じ総費用 C = wL + rK となる（L, K）の直線
* **傾き = −w/r**（絶対値 = 賃金率 w ÷ 資本レンタル価格 r）
* w・r 一定のとき異なる費用水準の等費用線は**平行**
* グラフが右に移動すると費用が大きくなる

## 等産出量曲線（等量曲線 / Isoquant）

- 生産量が等しくなる資本投入量と労働投入量の組み合わせを結んだもの
  - 生産量を一定とした場合、組み合わせは複数パターンある

* 同じ産出量 Q を実現できる（労働 L, 資本 K）の組み合わせの軌跡
* 右下がり・原点に対して凸の曲線
* 外側ほど産出量が多い

## 技術的限界代替率（MRTS）

* L を 1 単位増やしながら産出量を一定に保つために減らせる K の量
* **MRTS = MPL / MPK**（等量曲線の接線の傾きの絶対値）
* L が増えるにつれ MRTS は逓減（← 原点凸の理由）

## 費用最小化条件（最適生産点）

| 条件                               | 内容                                  |
| ---------------------------------- | ------------------------------------- |
| 等費用線と等量曲線の**接点** | 所与の産出量を最小費用で達成する点    |
| **MRTS = w/r**               | 等量曲線の傾き = 等費用線の傾き       |
| MPL / w = MPK / r                  | 1円あたりの限界生産物が両要素で等しい |

## グラフの各点

グラフは → [等費用線-等産出量曲線.html](等費用線-等産出量曲線.html)

```
K（資本量）
↑
C₁─ D ← C₁等費用線 と Q₁等量曲線の接点（Q₁の最適生産点）
C₀  G ← C₀等費用線 と Q₀等量曲線の接点（Q₀の最適生産点）
      E ← Q₁上・非接点（D より費用大、MRTS ≠ w/r）
         F ← C₁上・非最適点（Q₁ より産出量少）
────────────────────→ L（労働量）
    C₀      C₁
```

* **点 D**: C₁等費用線と Q₁の接点 → Q₁ の最小費用生産点（MRTS = w/r）
* **点 G**: C₀等費用線と Q₀の接点 → Q₀ の最小費用生産点（MRTS = w/r = D と同じ）
* **点 E**: Q₁上だが非接点 → D と産出量同じ、**費用は D より大きい**
* **点 F**: C₁上・非最適点 → L 減・K 増（→D 方向）で産出量増加できる

## 正誤判定の基準（第15問 a〜d）

| 選択肢                                          | 正誤         | 判定ポイント                                  |
| ----------------------------------------------- | ------------ | --------------------------------------------- |
| a: E は D より総要素費用が少ない                | **誤** | D が Q₁ の最小費用点 → E の費用 ≥ D の費用 |
| b: G は D より MRTS 同じ・産出量少ない          | **正** | 両点とも最適点 → MRTS = w/r；Q₀ < Q₁       |
| c: 費用一定で F から L 減・K 増で利潤増         | **正** | F→D の移動で Q が増加 → 利潤増              |
| d: 産出量一定で D から K 減・L 増で最適生産達成 | **誤** | D はすでに最適点；離れると費用増              |

**→ 正答: エ（a:誤 b:正 c:正 d:誤）**

## パレート効率性と生産（エッジワースボックス）

### 生産のパレート効率性

* ある要素配分において、**一方の企業の産出量を減らさずに他方の産出量を増やせない状態**
* 等量曲線の接点の軌跡 = **生産の契約曲線**がパレート効率的配分を示す

### エッジワースボックス（生産版）

* 2要素（L, K）を2企業間で配分する可能性空間を1つの箱に収めたもの
* 企業Aの等量曲線と企業Bの等量曲線が**接する点の軌跡 = 生産の契約曲線**
* 契約曲線上 → **MRTS_A = MRTS_B** → パレート効率的
* 契約曲線外 → 要素を再配分することで両企業の産出量を同時に増やせる（パレート改善可能）

### 費用最小化点との関係

* 各企業が同じ要素価格（w, r）のもとで費用最小化（MRTS = w/r）を行うと、すべての企業で MRTS が一致する
* → 市場均衡では**競争的要素市場を通じて自動的にパレート効率的な生産配分が実現**（厚生経済学の第一定理の生産側）

### 生産可能性フロンティア（PPF）との接続

* 生産の契約曲線の各点を「2財の産出量の組み合わせ」に変換したものが **PPF（生産可能性フロンティア）**
* PPF 上の傾き = **限界変形率（MRT）**
* PPF の内側 → パレート非効率（要素を再配分すればいずれかの財の産出量を増やせる）

## 派生的な重要知識

* **拡張経路（Expansion Path）**: 費用変化に伴う最適点の軌跡（D, G など）。MRTS = w/r を常に満たす
* **代替効果**: 要素価格が変化したとき、相対的に安くなった要素を多く使う（等費用線の傾き変化）
* **規模の経済**: 生産規模を均等に増加させたとき、産出量の増加率との比較
