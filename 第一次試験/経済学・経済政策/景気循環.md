# 景気循環

## 景気循環の周期

| 名称               | 周期       | 発生要因                             |
| ------------------ | ---------- | ------------------------------------ |
| キチンの波         | 40か月前後 | 在庫投資の変動                       |
| ジュグラーの波     | 7~10年     | 設備投資の変動                       |
| クズネッツの波     | 15~25年    | 建設活動の変動                       |
| コンドラチェフの波 | 40~60年    | 技術進歩、資源・エネルギーの制約など |

## キーワード

### ヒストリカルDI（ディフュージョン・インデックス）

* 個々の採用系列（先行系列・一般系列・遅行系列）ごとに山と谷を設定し、山から谷に至る期間は下降、谷から山に至る期間は上昇としてDIを作成したもの

## ポイント

* 景気循環の1周期は、一般的に景気の谷から次の景気の谷まで
* 景気の**谷から山にかけての期間は、景気の拡張期**（上昇期）、景気の**山から谷にかけての期間は、景気の収縮期**（下降期）
