## 費用曲線と完全競争均衡（第16問）★重要★

### 短期費用曲線の関係

グラフは → [費用曲線MC-AC-AVC.html](費用曲線MC-AC-AVC.html)

| 曲線 | 内容 | 形状 |
|------|------|------|
| MC（限界費用） | 産出量 1 単位追加のコスト | U 字型（底が最も低い） |
| AVC（平均可変費用） | 可変費用 ÷ 産出量 | U 字型 |
| AC（平均費用 / 平均総費用） | 総費用 ÷ 産出量 | U 字型（AVC より上） |

### 3曲線の交点（最重要）

* **MC = AVC の最小値点**（= **操業停止点**、価格 P₃）
  → MC 曲線は AVC の最小点を通過する
* **MC = AC の最小値点**（= **損益分岐点**、価格 P₁）
  → MC 曲線は AC の最小点を通過する

```
価格
↑  MC         AC
P₀ ─────────C
A=P₁──────D(AC最小)  AVC
B─────────E(AVC)
P₂
P₃──(AVC最小)
────────────────→ 生産量
O              Q₀
```

### 価格水準と企業行動

| 価格 | 条件 | 企業の状態 |
|------|------|-----------|
| P > P₁（AC最小） | P > AC | **超過利潤**あり（長期的に参入増加） |
| P = P₁ = AC最小 | P = AC | **損益分岐点**（正常利潤のみ） |
| P₃ < P < P₁ | AVC < P < AC | **損失** だが AVC < P → 生産継続（損失 < 固定費） |
| P = P₃ = AVC最小 | P = AVC | **操業停止点**（生産しても損失 = 固定費） |
| P < P₃ | P < AVC | **操業停止**（生産すると損失 > 固定費） |

### 生産者余剰の計算（設問1）

* **生産者余剰** = 総収入（TR） − 可変費用（VC）= （P − AVC） × Q
* グラフ上では：**価格水平線と AVC 曲線の間の面積**（= 四角形 P₀BEC）

```
価格 P₀ ─────────C（MC=P₀, Q=Q₀）
         │         │
  B ─────┼─────────E（AVC=B, Q=Q₀）
         │         │
  O ─────┼─────────Q₀  →生産量
```
→ **生産者余剰 = 四角形 P₀BEC**（答: オ）

### 各価格水準での損失（設問2）

| 価格 | 総収入 | 可変費用との比較 | 損失の大きさ |
|------|--------|----------------|------------|
| P = P₁（AC最小、=A） | TR = P₁·Q = AC·Q = TC | TR = TC | **損失ゼロ**（正常利潤） |
| P₃ < P₂ < P₁ | TR > VC（∵ P₂ > AVC） | TR − VC > 0 | **損失 = FC − (TR − VC) < FC** → 固定費の一部 |
| P = P₃（AVC最小） | TR = AVC·Q = VC | TR = VC | **損失 = FC**（固定費の全て） |
| P < P₃ | TR < VC | TR < VC | **損失 > FC**（操業停止が合理的） |

### よく問われる正誤パターン（設問2 a〜c）

| 選択肢 | 正誤 | 理由 |
|--------|------|------|
| a: P=P₁のとき TR = VC + FC | **正** | P₁ = AC最小 → TR = AC·Q = TC = VC + FC |
| b: P=P₂のとき損失は固定費の一部のみ | **正** | P₃ < P₂ < P₁ → P₂ > AVC → TR > VC → 損失 < FC |
| c: P=P₃のとき損失は可変費用のみ | **誤** | P₃ = AVC最小 → TR = VC → 損失 = FC（固定費のみ）|

**→ 設問2 正答: イ（a:正 b:正 c:誤）**

### 完全競争市場の短期均衡まとめ

* 企業は**価格受容者（プライステイカー）**: P = MR = AR
* 利潤最大化条件: **P = MC**（かつ MC が逓増）
* 供給曲線 = **MC 曲線の AVC 最小値より上の部分**
