# 費用曲線と完全競争均衡

## 短期費用曲線の関係

グラフは → [費用曲線MC-AC-AVC.html](費用曲線MC-AC-AVC.html)

| 曲線                        | 内容                      | 形状                   |
| --------------------------- | ------------------------- | ---------------------- |
| MC（限界費用）              | 産出量 1 単位追加のコスト | U 字型（底が最も低い） |
| AVC（平均可変費用）         | 可変費用 ÷ 産出量        | U 字型                 |
| AC（平均費用 / 平均総費用） | 総費用 ÷ 産出量          | U 字型（AVC より上）   |

## MC・AVC・ACの意味

費用曲線では、まず費用を3つに分けて考える。

```text
固定費 FC：生産量に関係なくかかる費用
可変費 VC：生産量が増えるほど増える費用
総費用 TC：固定費 FC + 可変費 VC
```

例えば工場を借りる費用は、作っても作らなくても発生するので固定費である。材料費や残業代は、生産量が増えるほど増えるので可変費である。

### MC（限界費用）

`MC` は「もう1個作ると、費用がいくら増えるか」を表す。

```text
MC = 総費用の増加分 ÷ 生産量の増加分
```

たとえば生産量を10個から11個に増やしたとき、総費用が1,000円増えたなら、MCは1,000円である。

MCは「平均」ではなく「追加分」で見る。完全競争では、企業は **追加で1個売る収入 P** と **追加で1個作る費用 MC** を比べて、生産量を決める。

```text
P > MC なら、もう1個作ると利益が増える
P < MC なら、もう1個作ると利益が減る
P = MC で、利益が最大になる
```

ここで混乱しやすいのは、同じ生産量 `Q` のところで読んだ `MC` と `AC` が、別の意味を持つことである。

例えば、ある価格と生産量で次のようになっていたとする。

```text
P  = 100円
MC = 100円
AC = 70円
```

これは、次の意味である。

```text
P  = 100円：1個あたりの売値が100円
MC = 100円：その生産量で、もう1個追加で作る費用が100円
AC = 70円 ：その生産量まで作ったときの、1個あたり平均総費用が70円
```

`MC = 100円` で `AC = 70円` というのは変に見えるが、平均点で考えると自然である。

```text
今までの平均点 = 70点
今回の点数     = 100点
```

ということがありえるのと同じで、`AC` は「これまで全体の平均」、`MC` は「追加の1個分」と考える。

この場合、

```text
P = MC
→ その生産量が利潤最大

P > AC
→ 1個あたり売値が平均総費用を上回る
→ 黒字
```

となる。つまり、**P = MC は生産量を決める条件**であり、**P と AC の比較は黒字か赤字かを見る条件**である。

MCがU字型になるのは、追加生産が最初は楽になり、途中から難しくなるからである。

例えば、短期では工場や機械の量は固定されている。そこに労働者を増やして生産量を増やすと考える。

```text
生産初期：
人を増やすと分業できる
→ 機械や設備を効率よく使える
→ 追加1個あたりの費用が下がる
→ MC は低下する

生産量が多くなった後：
工場や機械が混雑する
→ 人を増やしても生産量があまり増えない
→ 追加1個あたりの費用が上がる
→ MC は上昇する
```

この後半部分は、**限界生産力逓減** と対応している。労働を追加しても増える生産量が小さくなるため、1個追加で作るために必要な費用が大きくなる。

```text
限界生産力が上がる → 1個追加する費用は下がる → MC低下
限界生産力が下がる → 1個追加する費用は上がる → MC上昇
```

### AVC（平均可変費用）

`AVC` は「1個あたりの可変費用」である。

```text
AVC = VC ÷ Q
```

固定費は含めない。材料費や労務費など、生産をやめれば発生しない費用だけを平均したものと考える。

短期の操業判断では、この `AVC` が重要になる。価格 `P` が `AVC` を下回ると、売上だけでは可変費用すら回収できないため、生産するほど損失が大きくなる。

### AC（平均費用 / 平均総費用）

`AC` は「1個あたりの総費用」である。

```text
AC = TC ÷ Q
   = (FC + VC) ÷ Q
```

固定費も可変費も両方含めるので、`AC` は `AVC` より必ず上にある。

```text
AC = AVC + AFC
AFC = FC ÷ Q
```

ここで `AFC` は平均固定費である。固定費を1個あたりに割ったものなので、生産量 `Q` が増えるほど小さくなる。

## なぜU字型になるか

`AVC` や `AC` がU字型になるのは、生産量が少ない段階では効率がよくなりやすく、ある程度を超えると逆に効率が悪くなりやすいからである。

生産量が少ないうちは、設備や人員をうまく使えるようになり、1個あたり費用は下がる。しかし、生産量を増やしすぎると、混雑・残業・設備の限界などで、追加生産の費用が高くなる。

そのため、

```text
少量生産：1個あたり費用が高い
適度な生産量：1個あたり費用が低い
過大な生産量：1個あたり費用がまた高くなる
```

となり、`AVC` と `AC` はU字型になる。

試験では、特に **限界生産力逓減 → MC上昇** と、**MCがAC・AVCの最小点を通る** ことが重要である。

## 3曲線の交点（最重要）

* **MC = AVC の最小値点**（= **操業停止点**、価格 P₃）
  → MC 曲線は AVC の最小点を通過する
* **MC = AC の最小値点**（= **損益分岐点**、価格 P₁）
  → MC 曲線は AC の最小点を通過する

```
価格
↑  MC         AC
P₀ ─────────C
A=P₁──────D(AC最小)  AVC
B─────────E(AVC)
P₂
P₃──(AVC最小)
────────────────→ 生産量
O              Q₀
```

## 読み方の順序

- 完全競争では、企業は**市場価格を自分で決められない**

- したがって、企業にとって価格 `P` は横一直線に与えられる

見る順序は次のとおり。

1. 価格 `P` と `MC` が交わるところで、生産量 `Q` を決める
2. その `Q` の位置で、価格 `P` が `AC` より上か下かを見る
3. さらに、価格 `P` が `AVC` より上か下かを見る

つまり、まず **P = MC で数量を決める**。そのあと、**P と AC/AVC の上下関係で、利潤・損失・操業停止を判断する**。

## なぜ MC は AC / AVC の最小点を通るか

`AC` や `AVC` は「平均」、`MC` は「追加1単位の費用」である。

平均より低い追加費用が入ってくると、平均は下がる。平均より高い追加費用が入ってくると、平均は上がる。

そのため、

| 関係    | 平均費用の動き  |
| ------- | --------------- |
| MC < AC | AC は下がる     |
| MC > AC | AC は上がる     |
| MC = AC | AC は最小になる |

同じ理由で、`MC = AVC` のところで `AVC` も最小になる。

この「限界が平均を下から引き下げ、上から引き上げる」という関係を押さえると、MC が AC と AVC の最小点を通る理由が分かりやすい。

## 価格水準と企業行動

| 価格              | 条件         | 企業の状態                                               |
| ----------------- | ------------ | -------------------------------------------------------- |
| P > P₁（AC最小） | P > AC       | **超過利潤**あり（長期的に参入増加）               |
| P = P₁ = AC最小  | P = AC       | **損益分岐点**（正常利潤のみ）                     |
| P₃ < P < P₁     | AVC < P < AC | **損失** だが AVC < P → 生産継続（損失 < 固定費） |
| P = P₃ = AVC最小 | P = AVC      | **操業停止点**（生産しても損失 = 固定費）          |
| P < P₃           | P < AVC      | **操業停止**（生産すると損失 > 固定費）            |

## なぜ損失でも生産を続ける場合があるか

短期では、固定費 `FC` は生産してもしなくても発生する。したがって、操業するかどうかは、固定費ではなく **可変費用を回収できるか** で判断する。

判断基準は次の式で考える。

```text
利潤 = TR - TC
     = TR - VC - FC
```

もし `P > AVC` なら、総収入 `TR` が可変費用 `VC` を上回る。この場合、固定費の一部を回収できるので、生産した方が損失は小さい。

一方、`P < AVC` なら、総収入 `TR` だけでは可変費用 `VC` すら回収できない。この場合、生産すると固定費に加えて可変費用の赤字も増えるため、操業停止が合理的になる。

まとめると、

| 価格と AVC の関係 | 判断                                         |
| ----------------- | -------------------------------------------- |
| P > AVC           | 生産を続ける。固定費の一部を回収できる       |
| P = AVC           | 生産してもしなくても損失は固定費と同じ       |
| P < AVC           | 生産すると損失が固定費より大きくなるため停止 |

## 生産者余剰の計算

* **生産者余剰** = 総収入（TR） − 可変費用（VC）= （P − AVC） × Q
* グラフ上では：**価格水平線と AVC 曲線の間の面積**（= 四角形 P₀BEC）

```
価格 P₀ ─────────C（MC=P₀, Q=Q₀）
         │         │
  B ─────┼─────────E（AVC=B, Q=Q₀）
         │         │
  O ─────┼─────────Q₀  →生産量
```

## 生産者余剰と利潤の違い

ここで混同しやすいのは、生産者余剰と利潤の違いである。

```text
生産者余剰 = TR - VC
利潤       = TR - VC - FC
```

生産者余剰は、固定費を引く前の金額である。したがって、短期では **生産者余剰から固定費を引いたものが利潤** になる。

例えば `P₃ < P < P₁` の範囲では、`P > AVC` なので生産者余剰はプラスである。しかし `P < AC` なので、固定費まで含めると利潤はマイナスになる。

このため、「損失なのに生産継続」という状態が起きる。

## 消費者余剰

**消費者余剰**は、消費者が「払ってもよい」と思っていた金額と、実際に払った金額の差である。

```text
消費者余剰 = 支払意思額 - 実際に支払った金額
```

例えば、ある商品に120円まで払ってよいと思っていた人が、実際には100円で買えたなら、その人の消費者余剰は20円である。

グラフでは、消費者余剰は次の面積になる。

```text
需要曲線Dの下
価格線Pの上
数量0から取引量Qまで
```

ただし、このファイルの費用曲線グラフは、主に**企業1社の短期費用曲線**を見ている。そこには市場全体の需要曲線 `D` が描かれていないため、消費者余剰は直接読まない。

消費者余剰を見るときは、通常、次のような**市場全体の需要・供給グラフ**を使う。

```text
価格
↑
|\
| \  D
|  \   消費者余剰
|---\--------- P
|    \
|     / S
|____/____________→ 数量
     Q
```

完全競争市場では、需要曲線 `D` と供給曲線 `S` が交わって価格 `P` と取引量 `Q` が決まる。そのとき、**需要曲線Dと価格線Pの間の面積**が消費者余剰である。

整理すると、

```text
消費者余剰：需要曲線Dと価格線Pの間
生産者余剰：価格線Pと供給曲線/MC、またはAVCとの間
```
