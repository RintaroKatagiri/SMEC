費用曲線 MC・AC・AVC（第16問）

凡例

MC（限界費用）
AC（平均費用）
AVC（平均可変費用）
●CP₀ = MC（P₀での最適生産点）
●DMC = AC最小 = P₁（損益分岐点）
●EAVC(Q₀) = B
価格状態損益
P > P₁超過利潤利潤 > 0
P = P₁損益分岐点利潤 = 0
P₃ < P < P₁損失だが生産継続損失 < FC
P = P₃操業停止点損失 = FC
P < P₃操業停止損失 > FC
損失判定の数字例

Q=10個、AC=100円、AVC=70円とする。このとき FC=(AC−AVC)×Q=300円。

売値P判定計算
120円 黒字 P>AC。利潤=(120−100)×10=200円
100円 損益分岐 P=AC。利潤=(100−100)×10=0円
80円 損失だが生産継続 AVC<P<AC。損失=(100−80)×10=200円 < FC
70円 操業停止点 P=AVC。損失=(100−70)×10=300円 = FC
60円 操業停止 P<AVC。生産すると損失=(100−60)×10=400円 > FC
消費者余剰（市場全体の図）

この費用曲線の大きな図は企業1社の図なので、消費者余剰は直接読まない。消費者余剰は市場全体の需要曲線Dと価格線Pの間で見る。

図の読み方

位置関係:
AC は固定費を含むので、常に AVC より上にある。MC は AVC の最小点と AC の最小点を下から通過する。

注意:
C は P₀ と MC の交点なので Q₀ 上にある。D は AC 最小点であり、通常は Q₀ とは別の生産量にある。

生産者余剰（設問1）:
C は「P₀なら何個作るか」を決めるための点。長方形の下辺は MC ではなく、Q₀で読んだ AVC(Q₀)=B。
P₀ で生産するとき = TR − VC = (P₀ − AVC(Q₀)) × Q₀
= 四角形 P₀BEC（答: オ）
