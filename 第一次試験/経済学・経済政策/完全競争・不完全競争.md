# 完全競争・不完全競争

## 特徴

|                              | 完全競争市場 |         独占         |                 寡占                 |         独占的競争         |
| :--------------------------: | :----------: | :------------------: | :----------------------------------: | :------------------------: |
| 売り手、買い手ともに多数存在 |      〇      |    ×<br />(1社)    |            ×<br />(少数)            |             〇             |
|          財の同質性          |      〇      | -<br />(1社しかない) | 〇×<br />(ある場合とない場合がある) | ×<br />(ある程度の差別化) |
|    財に関する情報の完全性    |      〇      |          〇          |                  〇                  |             〇             |
|   市場への参入・退出の自由   |      〇      |          ×          |                  ×                  |             〇             |

## キーワード

### プライス・テイカー

* 自らの市場価値に影響を与えず、市場で決まる価格を受け入れるしかない経済主体のこと
* すべての参加者がプライス・テイカーである市場を完全競争市場という

### プライス・メイカー

* 価格支配力を持つ主体
* プライス・メーカーがいる市場のことを不完全競争市場という
