# 貿易自由化と余剰分析

## グラフで確認

* [輸出自由化の余剰分析グラフ](貿易自由化と余剰分析.html)

## どのケースか

* 閉鎖経済では、国内の需要曲線 `D` と供給曲線 `S` の交点 `E` で均衡する。
* 閉鎖経済での国内価格を `P0`、国内取引量を `Q0` とする。
* 国際価格 `Pf` が `P0` より高い場合、国内生産者は海外に売れるため、国内価格も `Pf` まで上昇する。
* これは「輸出国」のケースであり、国内消費者には不利、国内生産者には有利になる。

## 数量の変化

### 国際価格が国内価格より高い場合

* 国内価格は `P0` から `Pf` に上昇する。
* 国内消費量は `Q0` から `Q1` に減少する。
* 国内生産量は `Q0` から `Q2` に増加する。
* 輸出量は `Q2 - Q1` である。

### 判断の順番

* `Pf > P0` なら輸出ケースと判断する。
* `Pf` の高さで需要曲線を読むと、国内消費量 `Q1` が分かる。
* `Pf` の高さで供給曲線を読むと、国内生産量 `Q2` が分かる。
* 生産量 `Q2` から国内消費量 `Q1` を引いた分が輸出される。

## 余剰の読み取り

### 消費者余剰

* 消費者余剰は、需要曲線の下側かつ価格線の上側の面積である。
* 価格が `P0` から `Pf` に上がるため、消費者余剰は減少する。
* 問題図の面積番号に合わせると、消費者余剰の減少分は **`(1) + (2)`** である。
* `(2)` だけではなく、価格上昇によって既存消費分にも負担が生じる点に注意する。

### 生産者余剰

* 生産者余剰は、価格線の下側かつ供給曲線の上側の面積である。
* 価格が `P0` から `Pf` に上がり、生産量も `Q0` から `Q2` に増えるため、生産者余剰は増加する。
* 問題図の面積番号に合わせると、生産者余剰の増加分は **`(1) + (2) + (3)`** である。
* `(4)` は追加生産に必要な費用部分であり、生産者余剰ではない。

### 社会的総余剰

* 社会的総余剰は、消費者余剰と生産者余剰の合計である。
* 消費者余剰の減少分は `(1) + (2)`。
* 生産者余剰の増加分は `(1) + (2) + (3)`。
* したがって、社会的総余剰の増加分は次のように求める。

```text
社会的総余剰の増加分
= 生産者余剰の増加分 - 消費者余剰の減少分
= {(1) + (2) + (3)} - {(1) + (2)}
= (3)
```

## この問題の正誤判断

| 記述 | 判断 | 理由 |
| ---- | ---- | ---- |
| 国内消費量は `Q0` から `Q1` に減少する | 正 | `Pf > P0` により価格が上がり、需要量が減る |
| 消費者余剰の減少分は `(2)` である | 誤 | 正しくは `(1) + (2)` |
| 生産者余剰の増加分は `(1) + (2) + (3) + (4)` である | 誤 | 正しくは `(1) + (2) + (3)`、`(4)` は費用部分 |
| 社会的総余剰の増加分は `(3)` である | 正 | 生産者余剰増加分から消費者余剰減少分を差し引く |

## 試験での押さえ方

* まず `Pf` が `P0` より高いか低いかを見る。
* `Pf > P0` なら輸出ケースで、国内価格は上がる。
* 輸出ケースでは、国内消費量は減少し、国内生産量は増加する。
* 消費者余剰は減り、生産者余剰は増える。
* 社会的総余剰は、増えた余剰と減った余剰を差し引いて残った面積で判断する。
* 供給曲線の下側は生産費用なので、生産者余剰に含めない。

## 輸入ケースとの対比

| ケース | 価格 | 国内消費量 | 国内生産量 | 得をする主体 | 損をする主体 |
| ------ | ---- | ---------- | ---------- | ------------ | ------------ |
| `Pf > P0` | 上昇 | 減少 | 増加 | 生産者 | 消費者 |
| `Pf < P0` | 低下 | 増加 | 減少 | 消費者 | 生産者 |

## ひっかけポイント

* 「貿易自由化」とだけ読まず、国際価格が国内価格より高いか低いかを必ず確認する。
* 消費者余剰の減少を小さく読みすぎない。
* 生産者余剰に供給曲線の下側、つまり生産費用を含めない。
* 社会的総余剰は、消費者余剰と生産者余剰の変化を合算して判断する。
