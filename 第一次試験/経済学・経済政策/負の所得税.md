## 負の所得税（第21問）

### 制度の概要

* 低所得者に**定額給付 A** を行い、所得が増えるにつれ**比例税率 t** で給付を減らす（所得税を課す）
### 可処分所得（Yd）の公式
$$
Yd = Y(1 − t) + A
$$
※Y: 当初所得
※t: 比例税率（0 < t < 1）
※A: 定額給付（A > 0）

### グラフの読み方

グラフは → [負の所得税.html](負の所得税.html)

```
可処分所得
↑D
    /（45°線 OD: Yd = Y）
C  /
  /      ← 直線 C: Yd = Y(1-t)+A（傾き 1-t < 1）
A ╱ ← 縦軸切片 A（Y=0 のとき Yd = A = 給付額）
 ╱45°
O    Y₁  Y₂     Y₃  → 当初所得
```

* **直線 C の傾き**: 1 − t（< 1、∵ 0 < t < 1）
* **縦軸切片 A**: Y = 0 のときの可処分所得 = 定額給付額
* **損益分岐点（Y₁）**: C と 45°線 OD の交点 → Yd = Y → Y(1-t)+A = Y → **Y₁ = A/t**
  * Y < Y₁: Yd > Y（純給付状態）
  * Y > Y₁: Yd < Y（純課税状態）

### 各点の解釈

| 点 | 内容 |
|----|------|
| A（縦軸上） | Y=0 のときの可処分所得 = 定額給付 A |
| Y₁ | 損益分岐点（純給付 = 純課税の境界）= A/t |
| Y₂ | 直線 C 上の点（損益分岐点より右、課税領域）|
| Y₃ | 更に右（課税額大）|
| C | 直線 Yd = Y(1-t)+A |
| D | 45°線 Yd = Y |

### よく問われる正誤パターン（第21問 a〜d）

| 選択肢 | 記述 | 正誤 | 理由 |
|--------|------|------|------|
| a | 当初所得が 0 から Y₂ に増大するにつれ個人の純給付額は増加する | **誤** | Y₂ > Y₁ → Y₂ は課税領域 → 純給付額は Y₁ で 0 になり減少 |
| b | 当初所得が 0 から Y₁ に増大すると個人の可処分所得は増加する | **正** | C の傾き 1-t > 0 → Y 増加 → Yd 増加（Yd = Y₁(1-t)+A = Y₁ > 0） |
| c | 当初所得が Y₁ のとき、当初所得と可処分所得の金額は等しくなる | **正** | Y₁ = 損益分岐点 → C と 45°線の交点 → Yd = Y |
| d | 当初所得が Y₃ のとき、追加的な所得に対して税が課されている | **正** | Y₃ > Y₁ → 純課税状態 → 追加所得に t の税率が適用 |

**→ 正答: ウ（a と d）** ← 誤りは a、正しいのは b・c・d

実際の答え合わせ:
* a: 誤、b: 正、c: 正、d: 正 → 誤はaのみ → 答: ウ（aとd）は誤

正確には:
* a=誤, b=正, c=正, d=正 → 「正の組み合わせ」なら b・c・d → **正答: オ（b と d）**

| 選択肢 | 内容 |
|--------|------|
| ア | a と b |
| イ | a と c |
| ウ | a と d |
| エ | b と c |
| **オ** | **b と d** |

**→ 正答: オ（b と d）**

### 負の所得税の政策的意義

* **ワーキングプアへの支援**: Y が低くても Yd ≥ A が保証
* **就労インセンティブ**: 働くと Yd が増加（限界的に 1-t の割合で増加）
* **従来の生活保護との違い**: 所得が増えても突然打ち切られない（制度の連続性）
* **問題点**: 財政コスト大、行政コスト（所得把握）
