# 需要の弾力性

## グラフで確認

- [需要の弾力性グラフ](需要の弾力性.html)

## 弾力性が0とは

- 弾力性は、「あるものが1%変化したときに、別のものが何%変化するか」を表す
- 弾力性が0とは、原因となるものが変化しても、結果となるものがまったく変化しないことを表す
  - 価格弾力性が0：価格が変わっても需要量が変わらない
  - 所得弾力性が0：所得が変わっても需要量が変わらない
- 感覚的には、「相手が動いてもこちらは反応しない」という状態である
- 需要の価格弾力性が0の場合、需要曲線は垂直になる
  - 価格が上がっても下がっても、需要量が同じだからである
- 注意点として、「価格や所得が変化していないから弾力性が0」という意味ではない
  - 価格や所得が変化したにもかかわらず、需要量の変化率が0%である、という意味である

## 需要の価格弾力性

- 価格が1%変化したときに需要量が何%変化するかを表すもの

### 特徴

- 需要の価格弾力性が大きければ、需要量の変化率が価格の変化率に比べて大きくなる　→　価格の変化率がそれに伴う需要量の変化率に比べて大きいほど、需要の価格弾力性は小さくなる
- 代替品が豊富な財は、代替品に乏しい財に比べて、需要の価格弾力性は大きくなる
- 数量を横軸、縦軸を価格としたグラフにおいて、傾きが緩やかな需要曲線ほど、需要の価格弾力性は大きく、需要曲線が一定の価格水準において水平である場合、この財の需要の価格弾力性は無限大
- ある財の需要曲線が右肩下がりの直線である場合、より左上に位置する点の方が需要の価格弾力性が大きくなる
  ∵　価格の変化率が同じ1%の変化であっても価格が高いほうが変化の金額は大きくなり、需要量の変化率が大きくなるから

## 需要の所得弾力性

- 所得が1%変化したときに需要量が何%変化するかをあらわすもの

### 特徴

- 所得が増加したときに需要量が増加すれば所得弾力性は正、需要量が変化しなければ所得弾力性はゼロ、需要量が減少すれば所得弾力性は負となる

#### 所得効果

- 実質所得の変化を通じて生じる効果
- 実質所得が増加した状態で消費量が増加すれば所得効果は正、消費量が変わらなければ所得効果はゼロ、消費量が減少すれば所得効果は負

### 需要の所得弾力性による財の分類

$$
需要の所得弾力性（\eta）= \frac{需要量（消費量）Dの変化率}{所得mの変化率}=\frac{ΔD}{Δm}×\frac{m（基準時点）}{D（基準時点）}
$$

の数値で分類

| $\eta$の値   | 分類                                       | 詳細   |
| -------- | ------------------------------------------ | ------ |
| $\eta$≧1    | 上級財（所得の増加で消費量が増加する財）   | 奢侈財 |
| 1＞$\eta$＞0 | 上級財                                     | 必需品 |
| $\eta$＝0    | 中立財（所得の増加で消費量が変化しない財） |        |
| $\eta$＜0    | 下級財（所得の増加で消費量が減少する財）   |        |
