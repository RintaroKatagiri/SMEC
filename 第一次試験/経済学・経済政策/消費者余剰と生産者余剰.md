# 消費者余剰と生産者余剰

## グラフで確認

- [消費者余剰・生産者余剰グラフ](消費者余剰と生産者余剰.html)

## 消費者余剰

- 消費者が「支払ってもよいと思う最大の金額（支払意欲・留保価格）」と「実際に支払った価格」の差の合計
- 需要曲線の下側・価格の上側の面積（三角形）として表される
- 価格が下がると消費者余剰は増加し、価格が上がると減少する

### 計算方法

- 消費者余剰 = (支払意欲 − 実際価格) の合計
- グラフ上では：(均衡価格の最高点 − 均衡価格) × 均衡数量 ÷ 2

### 需要曲線と支払意思額の読み方

需要曲線の各点の縦軸の高さは、その数量を追加で1単位買うときの消費者の**限界価値**、すなわち限界的な支払意思額を表す。

```text
価格 P0、需要量 Q0 のとき

需要曲線の縦軸切片：A
需要曲線と価格線の交点：E

消費者の支払意思額（総便益） ＝ 需要曲線の下の面積 ＝ 四角形 OAEQ0
消費者の実際の支払額          ＝ P0 × Q0          ＝ 四角形 OP0EQ0
消費者余剰                    ＝ 支払意思額 − 実際の支払額
                              ＝ 三角形 AP0E
```

```text
価格
↑
│ A＼                 需要曲線上の高さ：限界価値
│   ＼
│ P0──E               実際の支払額：P0×Q0（長方形）
│     │
└─────Q0──→ 数量
```

* **支払意思額**は「実際に払った額」ではない。各単位に対して最大で払ってもよい額を合計した**総便益**である。
* 需要曲線が右下がりなので、購入量が増えるほど限界価値（需要曲線上の高さ）は低下する。
* 市場価格が下がると、消費者はより多く購入し、その追加分の限界価値は低い。ただし各単位について実際価格との差が大きくなるため、通常、消費者余剰全体は増加する。

### 面積問題の判定順序

1. 価格 `P0` から需要曲線まで水平にたどり、需要量 `Q0` を決める。
2. `P0 × Q0` の長方形を、**実際の支払額**として確定する。
3. `Q0` までの需要曲線の下側全体を、**支払意思額（総便益）**として読む。
4. 両者の差、すなわち価格線の上・需要曲線の下の部分を、**消費者余剰**として読む。

## 需要曲線のシフト：代替財と補完財

### 自らの価格変化と、他の財の価格変化

* **対象財自身の価格**が変化したときは、同じ需要曲線上を移動する。
  * 自らの価格が下落 → 需要量増加 → 需要曲線に沿って右下へ移動
  * 自らの価格が上昇 → 需要量減少 → 需要曲線に沿って左上へ移動
* **他の財の価格**や所得・嗜好が変化したときは、各価格における需要量そのものが変わるため、需要曲線が左右にシフトする。
  * 同じ価格で需要量増加 → **右シフト**
  * 同じ価格で需要量減少 → **左シフト**

### 代替財

代替財とは、一方の財の価格が上がると、もう一方の財に乗り換えるため、もう一方の財の需要量が増える関係にある2財である。

```text
A財の価格上昇
→ B財に乗り換える
→ B財の需要量増加
→ B財の需要曲線は右シフト

A財の価格下落
→ A財を選びやすくなる
→ B財の需要量減少
→ B財の需要曲線は左シフト
```

* 例：コーヒーと紅茶、バターとマーガリン

### 補完財

補完財とは、一緒に使用・消費されるため、一方の財の価格が下がると、もう一方の財の需要量も増える関係にある2財である。

```text
C財の価格下落
→ C財を買いやすくなる
→ 一緒に使うD財の需要量増加
→ D財の需要曲線は右シフト

C財の価格上昇
→ C財を買いにくくなる
→ D財の需要量減少
→ D財の需要曲線は左シフト
```

* 例：自動車とガソリン、プリンターとインク

### 試験での即答表

| 関係 | 一方の財の価格上昇 | もう一方の財の需要曲線 |
| --- | --- | --- |
| 代替財 | 他方に乗り換える | 右シフト |
| 補完財 | 一緒に買われにくくなる | 左シフト |

> 覚え方：**代替財は価格と逆方向、補完財は価格と同方向に、他方の需要量が動く。**

## 生産者余剰

- 生産者が「実際に受け取った価格」と「生産するために必要な最低限の価格（供給価格）」の差の合計
- 供給曲線の上側・価格の下側の面積（三角形）として表される
- 価格が上がると生産者余剰は増加し、価格が下がると減少する

### 計算方法

- 生産者余剰 = (実際価格 − 供給価格) の合計
- グラフ上では：(均衡価格 − 供給曲線の最低点) × 均衡数量 ÷ 2

## 社会的余剰（総余剰）

- 社会的余剰 = 消費者余剰 + 生産者余剰
- 完全競争市場の均衡では社会的余剰が最大化される（パレート最適）
- 市場介入（価格規制・税・補助金）により社会的余剰が損なわれることがある

## 死荷重（厚生損失）

- 市場の均衡から外れたとき（価格規制・税・独占など）に失われる社会的余剰
- 死荷重 = 自由均衡での社会的余剰 − 規制後の社会的余剰
- グラフ上では「消えた三角形」として現れる

### 価格規制（価格の上限・下限）

* 価格上限（最高価格）：均衡価格より低い価格に設定 → 需要超過・死荷重発生
* 価格下限（最低価格）：均衡価格より高い価格に設定 → 供給超過・死荷重発生

### 課税の効果

* 生産者に課税（従量税）：供給曲線が上方シフト → 均衡数量が減少
* 課税額は消費者と生産者で分担されるが、分担割合は弾力性に依存
* 弾力性が低い側が税を多く負担する
* 課税後：税収 < 失われた余剰 → 差額が死荷重

#### 弾力性と負担割合の対応関係

* 消費者の負担割合 = 供給の価格弾力性 ÷（供給の価格弾力性＋需要の価格弾力性）
* 生産者の負担割合 = 需要の価格弾力性 ÷（供給の価格弾力性＋需要の価格弾力性）
* この式から、**自分側の弾力性が大きいほど自分の負担割合は小さくなる**（相手側の弾力性が大きいほど自分の負担割合は大きくなる）
  * 需要の価格弾力性が大きい（消費者が価格に敏感）→ 消費者の負担割合は**小さくなる**
  * 供給の価格弾力性が小さい（生産者が価格に鈍感・傾きが急）→ 生産者の負担割合は**大きくなる**
* 極端なケースでの直感
  * 需要曲線が垂直（需要の価格弾力性＝0）→ 消費者が税を100%負担
  * 需要曲線が水平（需要の価格弾力性＝∞）→ 生産者が税を100%負担
  * 供給曲線が垂直（供給の価格弾力性＝0）→ 生産者が税を100%負担
  * 供給曲線が水平（供給の価格弾力性＝∞）→ 消費者が税を100%負担
* 誰（売り手・買い手）に納税義務があるかは負担割合と無関係　→　従量税を売り手に課しても買い手に課しても、経済的な負担配分（帰着）は弾力性だけで決まり同じになる（租税の中立性）

## 試験頻出ポイント

- 消費者余剰・生産者余剰・死荷重は**グラフ上の面積**として計算する
- 完全競争均衡 → 社会的余剰最大（死荷重ゼロ）
- 独占 → 死荷重が発生し、社会的余剰は完全競争より小さい
- 価格規制・課税は「誰の余剰が増え、誰の余剰が減るか、死荷重はいくらか」を問われる
- 課税の帰着は弾力性で決まる：非弾力的な側が多く負担
