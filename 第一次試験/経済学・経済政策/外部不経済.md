## 外部不経済（第18問）

### 外部性とは
* 市場取引を通じずに第三者へ影響を与える現象
* **外部経済（正の外部性）**: 第三者に便益 → 社会的便益 > 私的便益 → 過小生産
* **外部不経済（負の外部性）**: 第三者に損害 → 社会的費用 > 私的費用（or 社会的便益 < 私的便益）→ **過大消費**

### 第18問の設定（観光資源の負の外部性）

* 観光客増加 → 交通渋滞・ゴミ → **近隣住民への損害**（負の外部性）
* 私的限界価値曲線: **Db**（消費者の支払意欲）
* 社会的限界価値曲線: **D₁**（Db より下方 ← 外部不経済の分だけ社会的価値が低い）
* 供給曲線: **S**

グラフは → [外部不経済.html](外部不経済.html)

```
価格
↑C
A─────────G     S
          E──────────── Db
F    H    │
B─────────┼── D₁
          │
──────────┼────────────→ 数量
          社会最適  完全競争均衡
```

### 均衡の比較

| 均衡 | 数量 | 特徴 |
|------|------|------|
| **完全競争均衡** | S ∩ Db | **過大消費**（外部不経済を考慮しない） |
| **社会的最適** | S ∩ D₁ | 外部不経済を内部化した最適量（< 完全競争量） |

### 余剰・死荷重の各領域（第18問 a〜d）

グラフ上の点（上から）:
* C: 価格軸切片（Db の最大価格）
* A: S ∩ Db の価格（完全競争均衡価格）
* G: 完全競争均衡点（Db 上）
* E: Db 上（社会最適量での Db の価格）
* F: D₁ 上（社会最適量での D₁ の価格）
* H: S 上（社会最適量での供給価格）
* S: 社会最適均衡点（D₁ 上）
* B: 価格軸切片（D₁ の最大価格）

| 選択肢 | 正誤 | 理由 |
|--------|------|------|
| a: 完全競争均衡の死荷重 = 四角形 GFHE | **誤** | 死荷重は**三角形**（過大消費による余剰損失）≠ 四角形 |
| b: 完全競争均衡での外部不経済 = 四角形 CAHE | **誤** | 外部不経済の総量 = (Db − D₁) × 競争量 = 四角形（ただし領域が異なる） |
| c: 社会最適実現時の社会的余剰 = 四角形 CBFG | **誤** | 社会的余剰 = 三角形（各曲線の面積差） |
| d: 社会最適実現時の外部不経済 = 四角形 CAFG | **正** | 社会最適量での外部不経済の総面積 |

**→ 正答: エ（a:誤 b:正 c:誤 d:正）**  
※ 詳細は各選択肢のグラフ上の面積を図で確認

### 政策対応

| 手段 | 内容 |
|------|------|
| **ピグー税** | 外部不経済の大きさに等しい税を課す → 私的費用 = 社会的費用 |
| 規制 | 消費・生産の上限規制 |
| 補助金（外部経済の場合） | 過小生産を補正 |
| コース定理 | 取引費用ゼロなら当事者交渉で外部性を内部化可能 |

### 観光資源の具体例（第18問）

* 外部不経済: 観光客増加 → 渋滞・ゴミ → 近隣住民の損害
* Db（私的）> D₁（社会的）: 観光客は渋滞コストを負担しない
* 完全競争市場では過大な観光消費が発生
