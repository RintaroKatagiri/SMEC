需要の価格弾力性 = 需要量の変化率 ÷ 価格の変化率
  • |弾力性| > 1: 価格変化より数量変化が大きい。値下げで総収入は増えやすい。
  • |弾力性| = 1: 価格変化と数量変化の影響が釣り合う。総収入は最大付近。
  • |弾力性| < 1: 数量変化が小さい。値下げで総収入は減りやすい。
試験での見方

右下がりの直線需要曲線では、左上ほど弾力的、中央で単位弾力的、右下ほど非弾力的になる。

傾きで見る弾力性

緩やかな需要曲線

代替品が多い財は、価格が上がると他の財へ移りやすく、需要が弾力的になりやすい。

急な需要曲線

生活必需品や代替品が少ない財は、価格が変わっても需要が非弾力的になりやすい。

需要の所得弾力性

所得の変化に対して需要量がどの程度変化するかを示す指標。財の種類（正常財・上級財・劣等財）を判別する基準になる。

所得弾力性 = 需要量の変化率 ÷ 所得の変化率 = (ΔQ / Q) ÷ (ΔI / I)

財の分類

  • 上級財（奢侈財） η > 1

    所得が増えると需要量が所得増加率を上回って増える。ブランド品・旅行・外食など。

  • 正常財（必需財） 0 < η < 1

    所得が増えると需要量は増えるが、増加率は所得増加率より小さい。食料品・日用品など。

  • 中立財 η = 0

    所得が変化しても需要量は変わらない。塩など生活必需度が極めて高い財。

  • 劣等財（下級財） η < 0

    所得が増えると需要量が減る。インスタント食品・バス移動など、所得増加で上位財へ代替される財。

試験での見方

「所得弾力性がマイナス＝劣等財」は頻出。正常財の中でもη>1を「上級財」と呼ぶ点に注意。
