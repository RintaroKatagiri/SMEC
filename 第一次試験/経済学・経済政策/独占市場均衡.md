# 独占市場均衡

## 独占企業の特徴

* **価格支配力**あり（プライスメーカー）：需要曲線上で価格と数量を同時決定
* 需要曲線 D は右下がり → **MR（限界収入） < P（価格）** 常に成立
* MR 曲線は D 曲線より傾きが急（同じ縦軸切片、横軸切片は D の半分）

## MR と価格の関係

### MR（限界収入）

- 追加でもう一個売った時に、総収入がどれだけ増えるか
  - 完全競争においては、1企業は価格を変えられないので、`価格P=横一直線`（1企業が売る個数を変えたとて、市場価格は変わんない）
  - 独占企業は市場全体の需要を相手にしているので、**たくさん売りたいなら価格を下げる必要がある**
    -  すると、需要曲線Dは右肩下がりになり、その影響でMRは需要曲線Dより下にある

* **線形需要曲線** $P = a − bQ$ のとき $MR = a − 2bQ$
* MR の横軸切片 = D の横軸切片の **$\frac{1}{2}$**
* MR は D より **2倍急な傾き**

## 利潤最大化条件

```
利潤最大化: MR = MC　→　ここで生産量を決める
独占価格:   D 曲線から読み取り（MR=MC のときの Q₀ に対応する P）
```

## 価格形成原理
### 平均費用価格形成原理
- 「価格＝平均費用」となる水準に価格を規制すること
### 限界費用価格形成原理
- 「価格＝限界費用」となる水準に価格を規制すること

## 余剰分析

| 項目          | 完全競争          | 独占                                | 変化 |
| ------------- | ----------------- | ----------------------------------- | ---- |
| 価格          | MC=D の P         | B（> 競争価格）                     | 上昇 |
| 産出量        | 競争量（G〜I 間） | 独占量（< 競争量）                  | 減少 |
| 消費者余剰    | 大                | **三角形 ABF**                | 減少 |
| 生産者余剰    | -                 | **四角形 BCGF**（BC×独占量） | 変化 |
| 死荷重（DWL） | 0                 | **三角形 FGI**                | 発生 |

## よく問われる正誤パターン

| 選択肢                             | 正誤         | 理由                                                        |
| ---------------------------------- | ------------ | ----------------------------------------------------------- |
| a: 価格を C とすることで利潤最大化 | **誤** | MR=MC → 価格は B（C は MC 水準）。価格と MC を混同しない   |
| b: 消費者余剰は三角形 ABF          | **正** | A（需要曲線切片）〜B（独占価格）〜F（均衡点）の三角形       |
| c: 生産者余剰は四角形 CEHG         | **誤** | 独占生産者余剰 = 四角形 BCGF（価格 B と MC の差 × 独占量） |
| d: 死荷重は三角形 FGI              | **正** | 独占量と競争量の差に伴う余剰損失 = △FGI                    |

## 独占の弊害まとめ

* 価格 > MC（過小生産・過大価格）
* 死荷重（社会的余剰の損失）が発生
* **規制手段**: 限界費用価格規制（P = MC）、二部料金制、公的供給
