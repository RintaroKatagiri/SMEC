# 役務収益・役務原価

## 基本的な考え方

* 商品を販売せず、純粋に役務（サービス）を提供する企業では、提供したサービスの対価を役務収益として扱う。
* 基本的な処理では、サービスの提供が完了したときに役務収益を計上する。
* サービスの提供に直接かかった原価は、役務原価として同じ期間の費用にする。
* 役務収益と役務原価を対応させることが重要である。

## 提供完了前の処理

### 前受金

* サービスの提供が完了していない段階で受け取った対価は、まだ収益ではない。
* 提供義務が残っているため、前受金（負債）として処理する。

```text
（借）現金預金　XXX　／（貸）前受金　XXX
```

### 仕掛品

* サービスの提供が完了する前に発生した役務費用は、役務収益をまだ計上していないなら、いったん仕掛品（資産）に計上する。
* 仕掛品は、将来の役務収益に対応する未完成のサービス原価を表す。

```text
（借）仕掛品　130,000　／（貸）現金預金　130,000
```

## 提供完了時の処理

* サービスの提供が完了したら、前受金を取り崩して役務収益を計上する。
* 同時に、仕掛品を役務原価へ振り替える。

```text
（借）前受金　　XXX　／（貸）役務収益　XXX
（借）役務原価　XXX　／（貸）仕掛品　　XXX
```

* まだ代金を受け取っていない場合は、役務収益の相手勘定を売掛金などの債権とする。

## 仕訳の流れ

| 段階 | 収益側 | 原価側 |
| --- | --- | --- |
| 提供前に代金を受領 | 前受金（負債） | ― |
| 提供途中で原価が発生 | ― | 仕掛品（資産） |
| 提供完了 | 役務収益（収益） | 役務原価（費用） |

## 試験での注意点

* 前受金は現金を受け取ったことではなく、未履行のサービス提供義務があることを理由に負債となる。
* 提供途中の役務費用を直ちに役務原価にすると、まだ計上していない役務収益との対応関係が崩れる。提供完了まで仕掛品に計上する。
* サービスが一定期間にわたり提供され、進捗に応じて収益を認識する契約では、収益認識の詳細は[収益認識基準.md](収益認識基準.md)を参照する。
