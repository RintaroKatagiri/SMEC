# 時効

## 権利の時効

### 相続回復請求権

- 真正の相続人が、相続権の確認を求め、相続財産の返還など相続権侵害を排除して相続権を回復することを求める権利
- 相続回復請求権は、「相続人またはその法定代理人が相続権を侵害された事実を知った時から5年間行使しないときは、時効によって消滅する。相続開始の時から20年を経過したときも同様とする」と規定されている

### 人の身体に関する損害賠償請求

- けが・病気・死亡のように、人の生命または身体が害されたことによる損害賠償請求権は、被害者を保護するため、通常の損害賠償請求権より長い時効期間が定められている
- **債務不履行（契約違反）**による場合は、時効の完成猶予や更新がなければ、①被害者が請求できることを知った時から5年間、または②請求できる時から20年間行使しないときに時効が完成する
  - 【具体例】AがB病院で手術を受けたところ、B病院が契約上必要な安全確認を怠り、Aが大けがをしたとする。Aは、診療契約上の義務を果たさなかったとして、B病院に治療費などを請求できる
  - Aが「けがをしたこと」と「B病院に請求できること」を知ってから5年間何もしなければ、時効が完成する。たとえAが知らなかった場合でも、請求できる時から20年間を過ぎると時効が完成する
- **不法行為**による場合は、時効の完成猶予や更新がなければ、①被害者またはその法定代理人が損害および加害者を知った時から5年間、または②不法行為の時から20年間行使しないときに時効が完成する
  - 【具体例】Cが赤信号を無視して車を運転し、横断中のDに衝突してDが骨折したとする。Dは、Cに治療費や慰謝料を請求できる
  - Dが「骨折したこと」と「ぶつかった相手がCであること」を知ってから5年間何もしなければ、時効が完成する。また、事故から20年を過ぎても請求できない

## 時効期間を伸長する特約について

- 「永続した事実状態の尊重という時効制度の本来の趣旨をないがしろにすること」「債権者が債務者の窮状に乗じて、予め消滅時効の利益を放棄させるに等しい弊害を生じさせる可能性がある」などの理由で無効と解されている
  - 【具体例・伸長特約】AがBに10万円を貸す際に、「Aが返還を請求できる期間は20年とする」とあらかじめ約束した場合、この約束は法定の時効期間を伸ばすものであり、無効と解される
    - お金を借りるBは弱い立場になりやすく、「時効を使わない」と実質的に約束させられかねないためである
    - このような約束を認めると、20年後にも返還を請求され得る上、借用書や返済の証拠が失われているおそれもある。これは、時効によって法律関係を早期に安定させる目的に反する
- 時効期間を短縮する特約は、伸長の場合のような弊害は一般には考えにくいため、契約自由の原則に従って有効と解されている
  - 【具体例・短縮特約】AがBに10万円を貸す際に、「Aが返還を請求できる期間は2年とする」と約束した場合、この約束は原則として有効と解される
    - 2年を過ぎてもAが請求しなければ、Bは時効を援用できる。Aに早めの請求を促し、法律関係を早く確定させる方向の約束だからである

## 不法行為と債務不履行の消滅時効期間

|                                              | 不法行為                                                        | 債務不履行                                                                                    |
| -------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 一般の損害賠償請求権                         | ①損害および加害者を知った時から3年<br />②不法行為の時から20年 | ①権利を行使することが出来ることを知った時から5年<br />②権利を行使することができる時から10年 |
| 人の生命または身体の侵害による損害賠償請求権 | ①損害および加害者を知った時から5年<br />②不法行為の時から20年 | ①権利を行使することが出来ることを知った時から5年<br />②権利を行使することが出来る時から20年 |

※いずれも、①②のいずれが早いほうの時の経過をもって消滅時効が完成する
