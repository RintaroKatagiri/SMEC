# 吸収合併・会社分割・事業譲渡

## 全体像

|                  | 吸収合併                             | 吸収分割                                       | 事業譲渡                                             |
| ---------------- | ------------------------------------ | ---------------------------------------------- | ---------------------------------------------------- |
| 法的性質         | 組織再編                             | 組織再編                                       | 売買契約に類する個別の取引                           |
| 承継する範囲     | 消滅会社の権利義務の**全部**   | 事業に関する権利義務の**全部または一部** | 契約で定めた資産・負債・契約など                     |
| 承継の方法       | 包括承継                             | 指定した範囲での包括承継                       | 特定承継（原則として個別に移転）                     |
| 取引後の譲渡側   | 消滅会社は消滅する                   | 分割会社は存続する                             | 譲渡会社は存続する                                   |
| 対価の受取人     | 原則として消滅会社の株主             | 原則として分割会社（分割型では分割会社の株主） | 譲渡会社                                             |
| 効力発生日       | 合併契約で定めた日                   | 吸収分割契約で定めた日                         | 事業譲渡契約で定めた日。ただし、個別の移転手続が必要 |
| 債務・契約の移転 | 個別の債権者・契約相手方の承諾は不要 | 個別の債権者・契約相手方の承諾は不要           | 原則として個別の手続・承諾が必要                     |

* 吸収合併は、消滅会社の権利義務の全部を存続会社へ承継させる制度である（会社法第2条27号）
* 吸収分割は、株式会社または合同会社が、事業に関する権利義務の全部または一部を、既存の他社へ承継させる制度である（会社法第2条29号）
* 「吸収」とは、既存の会社が承継する形をいう。新しく会社を設立して承継させる場合は、それぞれ新設合併・新設分割という

## 効力発生日

### 吸収合併

* 吸収合併契約で定めた効力発生日に、存続会社が消滅会社の権利義務の全部を包括承継し、消滅会社は解散する（会社法第749条1項6号、第750条）
* 株主総会の承認や債権者保護手続など、必要な手続を経たうえで効力発生日を迎える
* 合併の効力自体は契約で定めた日に生じる。ただし、消滅会社の解散は、合併登記後でなければ第三者に対抗できない（同条2項）

### 吸収分割

* 吸収分割契約で定めた効力発生日に、承継会社が契約で定めた範囲の権利義務を包括承継する（会社法第758条1項7号、第759条）
* 分割会社は効力発生日後も存続し、承継対象外の事業・資産・負債を引き続き保有する
* 吸収合併と同様に、効力発生日までに必要な株主総会の承認や債権者保護手続を行う

### 事業譲渡

* 法律が一律に定める効力発生日はなく、事業譲渡契約で移転日を定める
* ただし、事業全体が一括して当然に移るわけではない。資産・債務・契約ごとに、必要な手続を満たした時点で移転の効力や第三者への対抗力が生じる
* 例えば、債務を譲受会社へ移して譲渡会社を免責するには債権者の承諾が必要であり、契約上の地位の移転には原則として契約相手方の承諾が必要である
* 不動産であれば登記、債権であれば債務者への通知または承諾など、対象ごとの対抗要件にも注意する

### 試験での見分け方

* **契約で定めた1日に、権利義務が一括して移る**なら、吸収合併または吸収分割
* **契約で定めた日でも、個別の承諾・登記・通知が必要**なら、事業譲渡

## 対価として選べるもの

* 対価とは、合併・会社分割・事業譲渡により事業や権利義務を受け取る会社が、相手方へ交付する財産をいう

### 吸収合併・吸収分割

* 吸収合併と吸収分割では、次のような財産を対価として選べる（会社法第749条、第758条）

| 対価の種類       | 内容                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 株式             | 吸収合併では存続会社、吸収分割では承継会社の株式を交付する                               |
| 社債             | 存続会社または承継会社の社債を交付する                                                   |
| 新株予約権       | 存続会社または承継会社の新株予約権を交付する                                             |
| 新株予約権付社債 | 存続会社または承継会社の新株予約権付社債を交付する                                       |
| 金銭             | 現金を交付する。吸収合併で金銭のみを対価とするものは、キャッシュ・アウト合併とも呼ばれる |
| その他の財産     | 親会社株式、不動産、債権など、上記以外の財産を交付する                                   |

* これを**対価の柔軟化**という。従来のように「承継会社自身の株式だけ」とは限られない
* 例えば、A社がB社を吸収合併するとき、B社の株主へA社株式を渡すほか、現金やA社の親会社株式などを渡すこともできる
* 完全親子会社間などでは、対価を交付しない無対価合併・無対価分割も可能である

### 事業譲渡

* 事業譲渡は組織再編ではなく契約であるため、会社法による対価の種類の限定はない
* 金銭が一般的だが、譲受会社の株式・社債、他の財産、債権などを対価とすることも、当事者の合意によって可能である

### 対価の受取人

* 対価の種類とは別に、誰が受け取るかも制度ごとに異なる

#### 吸収合併

```text
存続会社A社 ── A社株式・金銭等 ──> 消滅会社B社の株主
```

* B社は消滅するため、対価はB社そのものではなく、B社の株主に交付される
* A社株式を対価とする場合、B社の株主はA社の株主となる
* 金銭を対価とする場合、B社の株主は対価を受け取ってB社への出資関係を終える

#### 吸収分割

```text
吸収分割承継会社B社 ── B社株式・金銭等 ──> 吸収分割会社A社
```

* A社は存続するため、対価は原則としてA社が受け取る
* B社株式を対価とする場合、A社がB社の株主となる。これは、事業部門を子会社化する分社型のイメージである
* A社の株主がB社株式を直接受け取るわけではない
* 分割対価の全部をA社の株主へ交付する分割型吸収分割では、A社の株主がB社株式などを受け取る

#### 事業譲渡

```text
譲受会社B社 ── 金銭等 ──> 譲渡会社A社
```

* 事業譲渡はA社とB社の契約であるため、対価はA社が受け取る
* A社の株主が対価を直接受け取るわけではない。株主へ分配するには、別途、剰余金配当などの手続が必要となる
* 試験では、`消滅会社の株主が受け取る → 吸収合併`、`分割会社が受け取る → 吸収分割`、`譲渡会社が受け取る → 事業譲渡` と整理する

## 吸収合併

* 例：A社がB社を吸収合併する場合、A社は存続会社、B社は消滅会社となる
* 効力発生日に、B社の資産・負債・契約関係などの権利義務の全部が、A社へ包括的に承継される
* B社は法律上当然に解散し、法人格も消滅する
* 合併対価は、原則として存続会社の株式を消滅会社の株主へ交付する。ただし、金銭その他の財産を対価とすることもできる
* 債権者保護は、個別の承諾ではなく、公告・催告などの法定の債権者保護手続によって図られる

## 会社分割

* 例：A社の物流部門をB社へ移す場合、A社が吸収分割会社、B社が吸収分割承継会社となる
* 分割契約で定めた物流部門に関する資産・負債・契約関係などだけが、B社へ包括的に承継される
* A社は消滅せず、物流部門以外の事業を継続できる。全部の事業を承継させる場合でも、A社の法人格は当然には消滅しない
* 分割対価は、原則としてB社からA社へ交付される
* 承継の対象となる債務・契約について、個別の債権者・契約相手方の承諾を得ずに承継できる。その代わり、法定の債権者保護手続が置かれる

### 株式買取請求権

- 株式買取請求権が認められている
- 簡易株式分割には認められない

### 補足

- 会社分割では、吸収分割契約書などの事前開示書類を一定の期間、備置することが必要
- 会社分割においては、原則として、債権者保護手続を行うことが規定されている

## 事業譲渡

* 例：A社が物流部門をB社へ売却する場合、A社とB社の間で事業譲渡契約を締結する
* 移転する資産・負債・契約関係は契約で個別に定め、原則としてそれぞれの移転手続を行う
* 債務をB社へ移し、A社を免責するには、債権者の承諾が必要である
* 契約上の地位をB社へ移すには、原則として契約相手方の承諾が必要である
* A社は事業の全部を譲渡しても当然には消滅せず、他事業の継続または別途の解散・清算を選択できる
* 対価はA社が受け取り、金銭で支払われることが多いが、種類は当事者が契約で定める
* 事業譲渡そのものには、合併・会社分割のような法定の債権者異議手続はない

### 株式買取請求権

- 株式買取請求権が認められている
- 例外的に、反対株主の株式買取請求権は、事業の全部譲渡の場合、株主総会承認決議と同時に会社を解散する決議がされた場合には認められない
- 簡易事業譲渡も認められない

### 補足

- 事業譲渡は、事業を目的とする売買契約であるという諾成契約としての法的性質から、会社法は、書面の作成や備置を要件としていない
- 事業譲渡では、債権者を保護するための債権者保護手続は定められていない
  - これは、事業譲渡契約で**譲受会社が譲渡会社の債務を引き受ける**と約定しても、譲渡会社を債務から免れさせるには、債権者の個別の承諾が必要だからである
  - 具体例：A社が物流部門をB社へ譲渡し、部品仕入先C社に対する買掛金100万円を「B社が引き受ける」と契約した場合を考える
    - C社が承諾していなければ、C社は従来どおりA社に100万円を請求できる。A社とB社だけの合意では、C社との債権債務関係は変わらない
    - 理由は、C社はA社の信用力・資産・保証などを前提に取引しており、A社とB社が勝手に債務者をB社へ交代させると、C社の回収可能性が悪化するおそれがあるためである
    - C社が「A社を免責し、B社を新たな債務者とする」と承諾すれば、**免責的債務引受**となる。この場合、C社はB社に請求し、A社は債務を免れる（民法第472条）
    - A社を免責せず、B社にも債務を負わせる形は、**併存的債務引受**という。この場合、A社の債務は残る

## 簡易合併手続

* 存続会社において、合併対価の簿価が存続会社の純資産額の5分の1以下の場合には、存続会社にとってインパクトが小さいために株主総会の開催を不要とする制度
  * これに対して、消滅会社では、自社の法人格の消滅という重大な事項が関係するわけであるから、簡易手続は規定されておらず、株主総会の特別決議による承認が必要となる

### ポイント

* 簡易合併等の簡易手続の適用がある場合には、会社組織への影響が軽微であることから、株主総会の庄着が認められるので、そもそも株式買取請求権を認める前提条事情を欠く
  * そこで、簡易合併手続においては、存続会社における反対株主に株式買取請求権は認められない
  * 一方、簡易合併に該当する場合であっても、債権者保護手続は省略することができない
* 合併手続の流れ
  * ①合併契約の締結、②合併契約に関する書面の備置き、③株主総会の特別決議による承認（簡易合併の場合には省略できる）、④株式・新株予約権の買収請求（簡易合併の場合には認められない）、⑤会社債権者保護（異議）鉄手続き、⑥契約で定めた日に合併の効力発生、⑦合併事項書面等の備置き、⑧合併登記
  * 債権者保護手続は省略できず、会社債権者の異議申出期間は、1ヵ月を下回ることが出来ない
    * よって①から⑥までには必ず1ヵ月以上かかる
* 消滅会社の株主に交付する対価の全部または一部が孫ぞ9区会社の譲渡制限株式である場合であって、存続会社が株式譲渡制限会社であるときは、簡易合併の手続によることはできず、存続会社において株主総会特別決議は省略できない
  * これは、合併に伴って存続会社の譲渡制限株式が消滅会社の株主に交付されると、新たな株主が増加する結果となり、株式譲渡制限会社である存続会社の既存株主の利害を害するおそれがあるので、募集が部式の発行手続の場合と同様に、株主総会による特別決議が要求されるためである

## 試験での見分け方

* **会社が消える**なら、吸収合併
* **事業だけを切り出し、元の会社も残る**なら、吸収分割
* **債務や契約を移すのに個別承諾が必要**なら、事業譲渡
* 吸収合併・吸収分割は組織再編による包括承継、事業譲渡は契約による特定承継と押さえる
