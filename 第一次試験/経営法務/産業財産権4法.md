# 産業財産権4法
## 特許法
### 異議申し立て・無効審判制度
- 成立した特許権について、特許要件の具備に対して公開審査に付することを趣旨として、特許異議申立制度が設けられている
- 特許異議申立ては、何人も（利害関係に関係なく）、特許庁長官に対して、特許掲載公報の発行の日から6か月以内に限り、特許異議申立事由があることを理由に、することが出来る（特許法第113条）
    - 【具体例】A社の特許が2025年1月10日に特許掲載公報に掲載された場合、競合他社B社（利害関係なし）であっても、2025年7月10日までの間は異議申立ができる。それを過ぎると申し立て不可。
- 特許無効審判とは、特許権が、特許要件の規定違反や、特許事由に該当する場合に、当該特許の効力を争う利害関係を有する当事者が、その特許を無効とする審判を特許庁長官に請求する制度であり、利害関係人のみ、いつでも請求可能である
    - 【比較まとめ】異議申立：**何人でも・公報発行から6か月以内のみ** ／ 無効審判：**利害関係人のみ・いつでも**
- 特許異議申立ての理由となる事項は、①明細書や図面の補正に係る手続違反（特許法第11条1号）、②特許要件が書けること（同条2号）、③条約違反（同条3号）、④明細書の記載要件不備等、⑤外国語出願の場合の原文範囲外であること（同条5号）の5つとされる
    - これに対し、出願について発明の単一性の規定の要件を満たさない場合は、特許庁による審査の場面での拒絶理由とされるにとどまり、特許法第113条各号に規定される特許異議申立理由には掲げられていない
### 審査請求
- 特許法では、出願しただけでは審査は行われることはなく、審査請求があって初めて審査が開始される
- この審査請求は、出願人に限らず、だれでも請求することが出来る
### 出願公開
- 特許出願すると、原則として、特許出願の日から1年6か月を経過したときは出願公開される
    - 【具体例】2024年4月1日に出願 → 2025年10月1日（1年6か月後）に公開。公開前に競合他社が同様の製品を独自開発していた場合、公開後に特許存在を知って差止を受けるリスクがある。
- これに対して、不正競争防止法による営業秘密として保護されることが出来るが、営業秘密として保護される案件は、①秘密管理性、②有用性、③非公知性の3つ
    - 不正競争防止法は、「この法律において「営業秘密」とは、秘密として管理されている生産方法、販売方法その他の事業活動に有用な技術上または営業上の情報であって、公然と知られていないものをいう」と規定している
### 職務発明
- 特許法第35条3項は、「従業員がした職務発明については、契約、勤務規則その他の定めにおいて予め使用者等に特許を受ける権利を取得させることを定めたときは、その特許を受ける権利は、その発生時から、発明者である従業員に原始的に帰属する」
    - したがって、契約、勤務規則などにおいて、あらかじめ特に定めがなければ、っ特許を受ける権利は、その発生時から、発明者である従業者に原始的に帰属する
- 職務発明とは、従業者が、その性質上当該使用者の業務範囲に属し、かつその発明をするに至った行為が、その使用者における従業者の現在または過去の職務に属する発明のことを言う
    - 職務発明に該当するには、業務範囲であることのみならず、従業者の現在または過去の職務に属する発明であることが要件とされる
    - 例えば、開発命令を受けていない営業部員による発明といった、業務の範囲内ではあるが職務によらない発明は職務発明に該当しない
    - 【整理：職務発明の判定チェック】①会社の業務範囲内か？ ②従業者の職務（現在または過去）に属するか？ → 両方YESで初めて「職務発明」。①のみYES（業務範囲内だが職務外）は職務発明に**非該当**。
    - 【具体例・該当】製薬会社の研究員が、担当医薬品の開発業務中に新薬候補を発明 → ①②ともYES → 職務発明。特許を受ける権利は発生時から会社に帰属（事前の契約・勤務規則がある場合）。
    - 【具体例・非該当】IT企業の営業担当者が、趣味の電子工作で新しい回路を発明 → ①業務範囲外 → 職務発明に非該当。特許を受ける権利は従業者本人に帰属。
- 従業者は、職務発明について契約、勤務規則その他の定めにより使用者等に特許を受ける権利を取得させ、使用者等に特許権を承継させ、もしくは使用者等のため専用実施権を設定したときには、相当の金銭その他の経済上の利益（以下「相当の利益」という）を受ける権利を有する（特許法第35条4項）
    - 「相当の利益」は「経済上の利益」であることを要するため、単なる表彰などはこれに該当しないが、「経済上の利益」といえるものであれば、金銭の他、①使用者等負担による留学機会の付与、②ストックオプションの付与、③金銭的処遇の向上を伴う昇進または昇格、③法律および就業規則所定の日数・期間を超える有給休暇の付与、⑤職務発明に係る特許権についての専用実施権の設定または通常実施権の許諾などが含まれると解されている
- 職務発明をした従業者に対する「相当の利益」の付与については、「契約、勤務規則その他の定めにおいて相当の利益について定める場合には、相当の利益の内容を決定するための基準の策定に際して使用者等と従業者等との間で行われる協議の状況、策定された当該基準の開示の状況、相当の利益の内容の決定について行われる従業者等からの意見の聴取の状況等を考慮して、その定めたところにより相当の利益を与えることが不合理であると認められるものであってはならない。」（特許法第35条5項）とされ、「経済産業大臣は、発明を奨励するため、産業構造審議会の意見を聴いて、前項の規定により考慮すべき状況等に関する事項について指針を定め、これを公表するものとする」（同条6項）とされている
    - 同項に基づき「特許法第35条6項に基づく発明を奨励するための相当の金銭その他の経済上の利益について定める場合に考慮すべき使用者等と従業者等との間で行われる協議の状況等に関する指針」が定められr、公表されている
## 商標法
- 商標法は、保護対象となる商標を「人の近くによって認識することができるもののうち、文字、図形、記号、立体形状、もしくは色彩またはこれらの結合、音その他政令で定めるもの」としている
### 「動き商標」「立体商標」
- 「動き商標」は、「商標に係る文字、図形、記号、立体的形状または式性が変化するものであって、その変化の前後にわたるその文字、図形、記号、立体的形状もしくは色彩またはこれらの結合からなる商標のうち、時間の経過に伴って変化させるもの」と定義される
- そこで、文字を含んだ「動き商標」を商標登録することは、制度上認められている
- 「立体商標」は、「立体的形状（文字、図形、記号もしくは色彩またはこれらの結合との結合を含む）からなる商標」
- 人形のような立体的形状は商標登録の対象
    - 【具体例】ケンタッキーフライドチキンのカーネルサンダース人形（立体的形状）、コカ・コーラのくびれたボトル形状など。これらはそれ自体が商標として登録可能。
    - 【具体例：動き商標】テレビCMのオープニングで文字やキャラクターがアニメーション状に変化していく映像 → 動き商標として登録可能。
### 電子情報財
- 商標法は、平成14年の改正により、「商品または商品の包装に標章を付したものを譲渡し、引き渡し、譲渡もしくは引き渡しのために展示し、輸出し、輸入し、または電気通信回線を通じて提供する行為」として、「電気通信回線を通じて提供する行為」を加えることにより、インターネット等のネットワークを通じた電子情報財の流通・取引行為が、商品商標の使用行為に含まれることを明らかにしている
- また、「電磁的方法（電子的方法、磁気的方法その他、人の知覚によっては認識することが出来ない方法をいう）により行う映像面を介した役務の提供に当たりその映像面に標章を表示して役務を提供する行為」も加えて、電子情報財についての役務商標を保護することも規定している
#### 具体例
- 登録できる役務として「電子出版物の提供」が明記されている
- 電子化された雑誌の発行は、商品商標として登録することが可能 
### 専用・通常使用権
- 「商標権者は、その商標権について専用使用権を設定することが出来る」（商標法第30条1項本文）
    - この専用使用権の設定は、当事者間の設定契約に加えて、設定登録を行うことが、効力発生要件とされる
    - 【具体例】フランチャイズ本部Aが加盟店Bに対して、特定地域で自社ブランド商標を独占的に使用させる契約をする場合、契約だけでなく特許庁への設定登録まで完了して初めて専用使用権が発生する。
- 商標法における通常使用権については、特許権、実用新案権及び意匠権における通常実施権について当然対抗制度（当該権利の譲受人に対して、通常実施権の登録をしなくても対抗できる制度）が規定されているのに対して、当然対抗制度は認められない
    - そこで、商標権について通常使用権が許諾された後、その商標権が第三者に譲渡された場合において、通常使用権者が商標権の譲受人に対して通常使用権を対抗するためには、通常使用権の登録が必要である
    - 【具体例】A社（商標権者）がB社に通常使用権を許諾（登録なし）。その後A社がC社に商標権を譲渡。→ B社はC社に対して使用権を主張できない。登録していれば主張できた。
    - 【特許との比較】特許の通常実施権：登録なしでも譲受人に対抗可（当然対抗制度あり）／商標の通常使用権：登録しないと譲受人に対抗不可（当然対抗制度なし）
### 権利の移転
- 商標法における通常使用権の移転には、権利移転当事者間の合意があれば足り、移転の登録は不要である
    - 登録は、第三者に対する対抗要件である
- 当事者間の契約により商標権を譲受する場合、商標権の移転の効力は、当事者の合意に加えて、移転登録をすることによって移転の効力が発生する
    - 商標権の移転登録は、効力発生要件であり、対抗要件ではない
    - 【具体例】A社とB社が「A社の登録商標をB社に譲渡する」契約を締結した。しかし特許庁への移転登録前にA社が倒産し、C社が当該商標権を差し押さえた場合 → 登録が効力発生要件なので、未登録の段階ではB社に移転の効力が生じておらず、B社は権利を主張できない。
    - 【まとめ：移転における登録の位置づけ】通常使用権の移転：登録は**対抗要件**（当事者間では合意だけで有効）／商標権自体の移転：登録は**効力発生要件**（登録がないと移転の効力自体が生じない）
## 意匠法
### ポイント
- 令和2年4月1日施行の改定意匠法により、建築物の外観・内装デザインも保護対象に加えられた
- 改定意匠法では、「建築物（建築物の部分も含む）」を意匠に含めることとし、乾徳の外観も保護対象となる
- また、「店舗、事務所その他の施設の内部の設備および装飾（以下「内装」という）を構成する物品、建築物または画像に係る意匠は、内装全体として統一的な美感を起こさせるときは、一意匠として出願し、意匠登録を受けることが出来る」と規定する

## 横断的な制度
### 「不実施の場合の通常実施権の設定の裁定」制度
- 特許法及び実用新案法に設けられているが、意匠権及び商標法では設けられていない
- 特許法第83条1項は、「特許発明の実施が継続して3年以上日本国内において適当にされていないときは、その特許発明の実施をしようとする者は、特許権者または専用実施権者に対し通常実施権の許諾について協議を求めることが出来る。ただし、その特許発明に係る特許出願の日から4年を経過していないときは、この限りでない」とし、同条2項は、「前項の協議が成立せず、または協議をすることが出来ない時は、その特許発明の実施をしようとする者は、特許庁長官の裁定を請求することが出来る。」と規定する
    - これがいわゆる「不実施の場合の通常実施権の裁定制度」
    - これは、特許権者が発明を実施していない場合に、当該発明をを実施したい第三者との利益の調整を図る制度
    - そして、実用新案法第21条にも同様の規定が置かれている
    - 【具体例・タイムライン計算】
        - 2019年6月1日：A社が特許出願
        - 2020年3月1日：特許権成立（実施せず放置）
        - 2023年4月1日：B社が「3年以上不実施」を理由にA社へ許諾協議を申し入れ（継続3年以上なのでOK）
        - 協議不成立 → B社が特許庁長官に裁定請求したい
        - **出願日（2019年6月1日）から4年 = 2023年6月1日** → 2023年4月時点はまだ4年未経過のため**裁定請求は不可**
        - 2023年6月1日以降であれば裁定請求可能
    - 【ポイント整理】「3年以上不実施」で**協議要求**可 ＋「出願日から4年経過」で**裁定請求**可（両条件を満たす必要あり）
### 出願公開制度
- 特許法と商標法に設けられているが、実用新案法では設けられていない
### 異なる権利への出願の変更
- 産業財産権の各権利は、相互に異なる権利に出願を変更できる場合がある
- 例えば、特許出願、実用新案登録出願、意匠登録出願は、既に特許庁に係属する出願を、相互に他の権利の出願に変更することが出来る
- この変更出願がなされた場合、元の出願は取り下げられたものとみなされ、変更出願は、元の出願時になされたものとみなされる
- これに対して、商標登録出願は、商標法の範囲内において、通常の商標登録出願と団体商標、地域団体商標、防護商標登録出願との間での変更出願は認められているものの、特許法、実用新案権および意匠権といった異なる権利への出願変更は認められない

## 著作権（産業財産権には含まれていない）
### 写り込み
- 写真撮影、録音、録画の方法による、いわゆる「写り込み」は、撮影対象と付随的な対象著作物が分離困難であり、権利侵害の程度も極めて軽微であることから、著作権侵害とならないとされている
- 著作権法第30条の2は、写真撮影、録音、録画、放送その他これらと同様に事物の影像または音を複製し、または複製を伴うことなく伝達する行為を行うにあたって、①付随対象著作物の利用により利益を得る目的の有無、②付随対象事物等の分離の困難性の程度、③付随対象著作物が果たす役割その他の要素に照らし、正当な範囲内において、利用することが出来るとする、④ただし、付随対象著作物の種類及び用途ならびに当該利用の態様に照らし、著作権者の利益を不当に害することとなる場合は、この限りでない、とされる
    - 【具体例①・侵害なし】街頭で友人を撮影した際、背景のビルに掲示された絵画ポスターが写り込んだ → 分離困難・付随的なので著作権侵害にならない
    - 【具体例②・侵害あり】有名画家の絵画を「メインの被写体」として撮影し販売する行為 → 付随的ではなく「その絵画を撮ること自体が目的」なので写り込みの例外は適用されない
    - 【判断の軸】分離が困難か？ 付随的か？ 著作権者の利益を不当に害するか？ の3点で判断

## パリ条約（工業所有権の保護に関するパリ条約）
- 産業財産権全般の基本的条約として1883年に成立
- 内国民待遇の原則、優先権制度、相互独立の原則などを基本的考え方とする
### 内国民待遇の原則
- パリ条約第2条に定められており、「この条約で特に定める権利を害されることなく、ほかのすべての同盟国において、当該他の同盟国において、当該他の同盟国の法令が内国民に対し現在与えておりまたは将来与えることがある利益を享受する」というもの
#### 同盟国の国民とみなされる者
- 同盟に属しない国の国民であって、いずれかの同盟国の領域内に住所または現実かつ真正の工業上もしくは商業上の営業所を有するものは、同盟国の国民とみなす
### 優先権制度
- 産業財産権について、加盟国（第1国）に正規の出願をした者が、一定期間内に、別の同盟国（第2国）に同一の出願をした場合には、第1国での出願の時を基準として優先権を認める仕組み
- 例えば、日本国（同盟国）で特許又は実用新案の出願をした場合、ほかの加盟国（同盟国）で12か月以内（意匠や商標の場合には6か月以内）に同一の出願をし、パリ条約による優先権主張をすれば、先願の有無などについては、日本国での出願時を基準に判断されることになる
    - 【具体例・タイムライン】
        - 2025年1月15日：日本でX製品の特許を出願（第1国出願）
        - 2025年8月1日：競合C社が米国で同一発明を出願
        - 2026年1月14日：日本出願から12か月以内に米国へ同一の出願をし優先権主張
        - → 米国での審査において「先願」の基準日は**2025年1月15日**（日本出願日）となるため、2025年8月1日のC社出願より前とみなされ、X社が先願と判断される
    - 【優先権の期間まとめ】特許・実用新案：**12か月以内** ／ 意匠・商標：**6か月以内**
### 相互独立の原則
- 同盟国が付与した特許権等は独立のものであって、他の国（注：同盟国に限られない）における無効化を根拠として無効化されることはない
- 例えば、同一の発明で日本と米国で特許を取得した場合において、米国で当該特許が無効とされたとしても、それをもって日本国の特許が無効となるわけではない
    - 【具体例】A社が日・米・欧の3か国で同一発明の特許を取得。その後、米国でA社の特許が無効審決を受けた。→ 日本・欧州の特許はそれぞれ独立しているため、引き続き有効。逆に日本で有効期間が満了しても、米国・欧州の特許は影響を受けない。
### 工業所有権の保護対象
- 「工業所有権の保護は、特許、実用新案、意匠、商標、サービス・マーク、商号、原産地表示または原産地名称および不正競争の防止に関するものとする」と規定し、幅広い権利保護を定めている
