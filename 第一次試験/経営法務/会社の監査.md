# 会社の監査

株式会社の監査は、「会社を動かす人を、誰がチェックするか」で整理すると分かりやすい。

試験用には、次の3パターンを並列で押さえる。

| パターン                                 | 監査する機関     | 監査する人は取締役か | 会社を動かす人             | 会社を代表する人 | 覚え方                             |
| ---------------------------------------- | ---------------- | -------------------- | -------------------------- | ---------------- | ---------------------------------- |
| 監査役設置会社（監査役会設置会社を含む） | 監査役・監査役会 | 取締役ではない       | 代表取締役・業務執行取締役 | 代表取締役       | 取締役とは別に監査役がチェックする |
| 監査等委員会設置会社                     | 監査等委員会     | 取締役               | 代表取締役・業務執行取締役 | 代表取締役       | 取締役の中に監査担当を置く         |
| 指名委員会等設置会社                     | 監査委員会       | 取締役               | 執行役                     | 代表執行役       | 執行役を3委員会で監督する          |

## 分類の注意

- 厳密には、「監査役設置会社」は監査役を置く会社全般を指す
- 「監査役会設置会社」は、監査役設置会社のうち、監査役会まで置くタイプである
- 監査等委員会設置会社や指名委員会等設置会社は、監査役を置かない
- 大会社などの機関設計を比べるときは、「監査役会設置会社」「監査等委員会設置会社」「指名委員会等設置会社」の3つで並べると理解しやすい
- このノートでは、監査役を使うタイプを「監査役設置会社（監査役会設置会社を含む）」として1枠にまとめる

## 機関設計と設置義務

- 株式会社には、1人または2人以上の取締役を置かなければならない（会社法第326条1項）
- 取締役会、会計参与、監査役、監査役会、会計監査人、監査等委員会、指名委員会等は、原則として定款で置く任意機関である（会社法第326条2項）
- ただし、公開会社、監査役会設置会社、監査等委員会設置会社、指名委員会等設置会社は、取締役会を置かなければならない（会社法第327条1項）
- したがって、非公開会社であることだけを理由に取締役会が必要になるわけではない
- 非公開会社では、取締役会を置かず、取締役1名だけの設計も可能である
- 取締役会設置会社（監査等委員会設置会社・指名委員会等設置会社を除く）は、原則として監査役を置かなければならない（会社法第327条2項本文）
- ただし、公開会社でない会計参与設置会社は、例外として監査役を置かなくてよい（会社法第327条2項ただし書）
- 試験用には、`取締役会設置会社は必ず監査役が必要` は例外を見落とした誤り、`非公開会社は必ず取締役会が必要` も誤り、と押さえる

## 任期

| 役員・機関                   | 原則の任期 | 試験用の押さえ方                                                               |
| ---------------------------- | ---------- | ------------------------------------------------------------------------------ |
| 取締役                       | 原則2年    | 定款または株主総会決議で短縮できる。非公開会社では定款で最長10年まで伸長できる |
| 監査役                       | 原則4年    | 取締役より長い。独立性を守るため、短縮はできない                               |
| 会計監査人                   | 原則1年    | 毎年の定時株主総会ごとに見直されるイメージ                                     |
| 監査等委員でない取締役       | 原則1年    | 監査等委員会設置会社では、業務執行側の取締役は毎年チェックされる               |
| 監査等委員である取締役       | 原則2年    | 監査する側なので、業務執行側より任期が長い                                     |
| 指名委員会等設置会社の取締役 | 原則1年    | 委員会型の会社では取締役を毎年チェックする                                     |

- 取締役の任期は通常1年ではなく、原則2年である
- ただし、会社法459条のように、定款で剰余金の配当を取締役会が決定できるようにする場面では、取締役の任期が1年を超えないことが要件になる
- これは、株主総会を経ずに配当を決められる分、株主が毎年取締役を選び直してチェックできる体制を求める趣旨である
- 試験用には、`通常の取締役任期は2年`、`459条の取締役会配当では1年任期が必要` と分けて覚える

## 監査等委員会設置会社

- 監査等委員会設置会社とは、監査等委員会を置く株式会社である（会社法第2条11号の2）
- 監査等委員は、取締役である
- 監査等委員である取締役は3人以上必要で、その過半数は社外取締役でなければならない
- 監査等委員会設置会社では、大会社であるか否かに関わらず、会計監査人を置かなければならない
- 会社を代表して業務を動かすのは、代表取締役である
- 代表取締役は、監査等委員ではない取締役の中から選ぶ
- 指名委員会等設置会社と異なり、制度上「執行役」は置けない
- 試験用には「代表取締役が会社を動かし、取締役の中の監査等委員会がチェックする会社」と覚える

## 指名委員会等設置会社

- 指名委員会等設置会社とは、指名委員会・監査委員会・報酬委員会の3つの委員会を置く株式会社である
- 指名委員会は、取締役候補者の選任・解任に関する議案内容を決める
- 監査委員会は、取締役や執行役の仕事をチェックする
- 報酬委員会は、取締役や執行役の報酬内容を決める
- 3つの委員会の委員は、取締役の中から取締役会が選ぶ
- 3つの委員会は、それぞれ委員3人以上で、その過半数は社外取締役でなければならない
- 監査委員は、執行役や使用人を兼ねることができない
- 会社を実際に動かすのは、執行役である
- 会社を代表するのは、代表執行役である
- 取締役を兼ねる代表執行役がいても、法律上は「代表取締役」ではなく「代表執行役」と整理する
- 試験用には「執行役が会社を動かし、指名・監査・報酬の3委員会で監督する会社」と覚える

## 監査役設置会社（監査役会設置会社）

- 監査役設置会社とは、監査役を置く株式会社である
- 監査役は、取締役ではない
- 代表取締役や取締役の仕事を、取締役とは別の立場からチェックする
- 監査役は、取締役・使用人・執行役を兼ねることができない
- 監査役会設置会社では、監査役は3人以上必要で、その半数以上は社外監査役でなければならない
- 監査役会設置会社では、監査役会が常勤監査役を選定しなければならない
- 試験用には「取締役とは別枠の監査役がチェックする会社」と覚える

### 取締役の選任と解任

- 株主総会の決議は、定款に別段の定めがある場合を除き、議決権を行使することが出来る株主の過半数を有する株主が出席し（定足数）、出席した当該株主の議決権の過半数をもって行う（普通決議）のが原則である（会社法第309条1項）
  - 定足数定款に定めることによって、原則として任意に定めることができる
  - しかし、役員を選任および解任する場合の株主総会の定足数は、議決権を行使できる株主の議決権の3分の1を下回ることが出来ない
  - そこで、取締役及び監査役の選任の解任について株主総会の定足数は、原則として議決権を行使することができる株主の議決権の過半数が必要であり、定款に定めることによって、定足数を3分の1まで軽減することができるということになる
- 次に、取締役の選任および解任は、株主総会の普通決議によってなされる（会社法第329条1項、339条1項）
  - これに対し、監査役については、選任は取締役と同様に株主総会普通決議によってなされる（会社法第329条1項）が、解任については株主総会特別決議（出席した株主の議決権の3分の2以上）によることが必要である

### 取締役会の招集

- 会社法上、監査役は、取締役が不正の行為をし、もしくはその恐れがあると認めるとき、または法令もしくは定款に違反する事実もしくは著しく不当な事実があると認める場合において、必要があると認めるときは、取締役会の招集を請求し、その請求があった日から5日以内に、その請求があった日から2週間以内の日を取締役会の日とする取締役会招集の通知が発せられない場合は、その請求をした監査役自らが取締役会を招集することが出来る
  - ちなみに、この監査役自らによる取締役会招集は、特別取締役による取締役会には適用されない
- 取締役会の招集通知は、株主総会のそれとは異なり、任意の方法で発すればよく、会議の目的事項等を特定して行う必要はない
- 取締役会を招集するものは、取締役会の日の1週間（これを下回る期間を定款で定めた場合にあっては、その期間）前までに、各取締役（監査役設置会社にあっては、各取締役および各監査役）に対してその通知を発しなければならない
  - 取締役会の招集通知を監査役に対しても発しなければならないのは、監査役は、取締役会に出席する義務があり、必要があると認めるときは、意見を述べなければならない
  - ただし、例外として、特別取締役による取締役会には、監査役の全員が出席する必要はないとされている

#### 特別取締役

- 特別取締役とは、取締役の数が6人以上で、そのうち1人以上が社外取締役である取締役会設置会社では、あらかじめ3人以上の特別取締役を選定することができ、特別取締役による取締役会決議により、重要な財産の処分・譲受けと多額の借財の決定を行うことが出来る
- この特別取締役による取締役会の招集については、監査役自らが行うことはできない

### その他

- 監査役の報酬は、定款または株主総会決議によって定めなければならない
- 監査役は、いつでも、取締役、会計参与、支配人その他の使用人に対して、事業の報告を求め、または自ら会社の業務及び財産の状況の調査をする権限を有する
  - 例外として、株式譲渡制限会社では、定款に定めることにより、監査役の監査権限の範囲を会計監査に限定することが出来る

## キーワード

### 監査役

- 監査役の報酬については、監査役の地位の独立性を担保するために、定款または株主総会決議によって定めなければならないとしている（会社法第387条1項）
  - また、監査役が2人以上いる場合においては、各監査役の報酬等について定款または株主総会決議がない場合は、定款または株主総会決議で定めた報酬の総額の範囲内で、監査役の協議によって定める（同条2項）
  - 2項は、監査役が複数いる場合の「総額の範囲内での配分」の話である
    - 例えば、株主総会で「監査役全体の報酬総額は年900万円以内」とだけ決めた場合、監査役Aと監査役Bにどう配分するかまでは株主総会で決めていない
    - この場合、`A監査役：500万円`、`B監査役：400万円` のような個別配分は、監査役同士の協議で決める
    - 試験用には、`監査役報酬の総額 → 定款または株主総会`、`各監査役への配分 → 監査役の協議`、`取締役会が決める → 誤り` と押さえる
- 監査役を含む役員及び会計監査人と会社の関係は、委任（民法第643条）の規定に従う（会社法第330条）
  - そこで、委任契約と同様に、役員及び会計監査人は、いつでも、株主総会の決議によって解任することが出来る（会社法第339条1項）
  - この場合、監査役の解任については、株主総会の特別決議に依らなければならない（会社法第341条、343条4項、309条2項7号）
  - 解任されたものは、その解任について「正当な理由」がある場合を除き、株式会社に対して、解任によって生じた損害の賠償を請求することが出来る（会社法第339条2項）
  - 以上のように、株式会社が役員を解任することは自由であり、「正当な理由」の有無は、損害賠償の問題となる場合だけであって、正当な理由が無ければ解任することが許されるわけではない

#### 常勤監査役

- 株式会社の営業時間中、その株式会社の監査役としての職務を行うもの
- 会社法第390条3項は、「監査役会は、監査役の中から常勤の監査役を選定しなければならない」と規定しているが、同条同項の監査役からは社外監査役は除外されず、他に会社法には、社外監査役が常勤監査役を兼任することを禁止する銘文の規定もないことから、監査役会が決議すれば、社外監査役を常勤監査役に選定することは、可能であると解される

## 3つの違い

- 監査役設置会社では、取締役とは別の「監査役」がチェックする
- 監査等委員会設置会社では、取締役の中の「監査等委員会」がチェックする
- 指名委員会等設置会社では、取締役の中の「監査委員会」がチェックし、会社を動かすのは執行役である
- 監査等委員会設置会社と指名委員会等設置会社は、どちらも監査する人が取締役である点で似ている
- 監査等委員会設置会社と監査役設置会社は、どちらも代表取締役が会社を代表する点で似ている
- 指名委員会等設置会社だけは、代表取締役ではなく代表執行役が会社を代表する

## 名前のひっかけ

| 名前         | 置かれる会社         | 監査する人             |
| ------------ | -------------------- | ---------------------- |
| 監査役会     | 監査役会設置会社     | 監査役                 |
| 監査等委員会 | 監査等委員会設置会社 | 監査等委員である取締役 |
| 監査委員会   | 指名委員会等設置会社 | 監査委員である取締役   |

- 「監査役会」と「監査委員会」は別物である
- 「監査等委員会」と「監査委員会」も別物である
- 指名委員会等設置会社の3委員会すべてが監査をするわけではなく、監査を担当するのは3つのうち「監査委員会」である

- 伊藤忠商事
